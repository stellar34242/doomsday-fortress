## 1. 世界单位换算

- `32 像素 = 1 单元格 = 3.2 米`。代码来源：`src/game/config.ts`，搜索 `BASE_CELL`、`M_PER_CELL`。
- 编辑器和游戏参数界面统一使用米，不显示厘米。
- 本文所述像素值均指原始比例；实际绘制尺寸会随战场缩放比例变化。
- 基准视口为横向 `20×12格`，即 `64×38.4m`；全屏画布、屏幕比例和缩放会改变实际可见范围。代码来源：`src/game/config.ts`，搜索 `VIEW_COLS`、`VIEW_ROWS`。

### 1.1 显示模式与参考分辨率

游戏参数的“画面设置”提供两种显示模式：

- **自适应**：默认模式，完全沿用当前逻辑；战斗画布填满可用屏幕，屏幕越宽或越高会显示更多战场。
- **固定参考分辨率**：战斗 Canvas、战斗 HUD 和战场悬浮面板使用所选参考分辨率作为统一逻辑视口，再保持宽高比完整缩放到设备可用区域；不拉伸、不裁切，未占用区域显示黑色。

固定模式提供 `1280×720`、`1366×768`、`1600×900`、`1920×1080`、`2560×1440`、`1920×1200`、`2340×1080`、`2400×1080` 八个预设，覆盖常用 PC、平板和手机横屏比例。默认参考值为 `1920×1080`，但默认显示模式仍为自适应。

- 参考分辨率只控制游戏逻辑画面，不会修改操作系统或浏览器窗口分辨率。
- 关卡编辑器始终保持自适应，避免左右编辑面板挤压画布。
- 默认、最小和最大缩放仍独立生效；固定模式只改变逻辑视口尺寸和屏幕适配倍率。
- 固定模式的 Canvas 缓冲区直接使用参考分辨率，不再额外叠加设备 DPR；自适应模式继续将 DPR 上限限制为 `2`。
- 旧版仅含缩放值的显示配置读取后自动迁移为自适应模式。
- 配置、预设与迁移代码来源：`src/game/displayConfig.ts`，搜索 `DISPLAY_RESOLUTION_PRESETS`、`normalizeDisplayConfig`。
- 视口等比适配代码来源：`src/game/displayConfig.ts` 与 `src/components/GamePreview.tsx`，搜索 `resolveDisplayViewport`、`canvasDisplayScale`。

### 2.1 两层视野结构

当前只采用以下两层，不生成“未探索区域”历史：

1. 可见层：视野覆盖范围内正常显示。
2. 视野外阴影层：覆盖 50% 黑色战争迷雾，保留约 50% 的场景亮度。

关卡编辑器不显示战争迷雾；该功能只在实际战斗中生效。

### 2.2 共享视野来源

- 玩家当前主控单位、玩家阵营单位和友方单位都会贡献视野。
- 所有有效视野源取并集，重叠区域不会重复加深或重复增亮。
- 多人 PVP 中，同阵营玩家及同阵营单位共享视野。
- 每个视野源当前使用相同的玩家共享视野半径：`64m / 20格`。

### 2.3 边缘渐变规则

- 视野中心至半径 `18格` 的区域完全移除战争迷雾。
- 从第 `18格` 到第 `20格` 进行两格宽的径向渐变。
- 到达第 `20格` 边界时恢复为完整的 50% 黑色遮罩。
- 缩放战场时，渐变仍保持两格的世界宽度，不固定为屏幕像素宽度。
