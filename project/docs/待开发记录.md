## 1. 堡垒装甲系统（需求已定稿）
- 四向装甲值（前/后/左/右）；伤害低于受击面装甲 → 完全格挡；伤害 ≥ 装甲 → 溢出部分（dmg − armor）伤**结构值**（原名防御值，UI 更名，内部键保留兼容）
- 穿甲武器：命中时一部分伤害穿透装甲直入结构 + 削弱该面装甲值；装甲削穿后低攻武器可直伤结构
- 模块可修复装甲值与结构值
- 受击面判定统一函数：弹丸按弹道与船体矩形的实际命中边、近战按接触边、AOE 按爆心方位；角部归属统一用矩形对角线裁决

- **工作量：中**（堡垒承伤现为单点入口，改造面干净；复杂度在方向判定、削甲状态化与三处 UI）

## 14. 防御能量罩（防御盾发生器模块，设定已定稿）
- **承伤顺序**：护盾 → 装甲 → 结构值；护盾归零的那一击，溢出伤害继续走装甲判定（不外溢直伤结构）；穿甲武器对护盾无效（pen 只在装甲层生效）；接入统一承伤入口 damageFortress
- **开关**：装上发生器即常驻开启、无法手动关闭；满盾时不耗电，仅回复过程耗电，电量耗尽停止回复
- **回复机制**：有电即持续回复（`shieldRegen/s`）；**盾破后脱战前不再回复**，脱战判定 = 10s 内未受攻击；发生器模块自带基础回复速度与基础护盾最大值
- **模块体系**：发生器**限装一台**；另有增效模块可提升护盾回复效率、提升最大护盾值
- **美术表现**：包裹战车矩形面积的**多边形罩**（低饱和青白、呼吸微光）；受击命中点涟漪闪光（复用 fxSeen 事件模式）；罩破碎裂粒子；与战损痕迹（第 13 项）联动——护盾期间本体不留痕迹
- 未来敌对堡垒带护盾时同一机制直接复用
- **工作量：中**（承伤入口与模块系统均有现成挂点；复杂度在脱战判定状态机、多边形罩渲染与增效模块数值体系）

## 19. 堡垒碰撞系统（碾压单位 + 堡垒撞堡垒合并）
- **碾压**（可先行）：移动堡垒 footprint 覆盖敌人 → 碾压伤害（车速 × 车重档位缩放）+ 沿运动方向击退；大体型敌人只受伤、击退衰减；堡垒无反作用保持载具爽感；可选子项：敌人规避 AI（堡垒驶近时短距侧移，联动 #21 skirmish 原型）
- **堡垒撞堡垒**（依赖敌对堡垒实体，排后）：事件式冲撞——矩形重叠瞬间按相对速度 + 车重比结算冲撞伤害，双方走 #1 统一承伤入口（受击面 = 接触边）；重者微减速、轻者被顶退
- 机制变更，sim 需补碾压回归用例（伤害确定性，好测）
- **工作量：中**（碾压部分）；冲撞部分随敌对堡垒实体另计
