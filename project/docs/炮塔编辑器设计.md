## 1. 总览与类型体系

### 1.1 炮塔域范围

炮塔域负责炮塔定义（`TurretDef` 数值参数、槽位尺寸 S/M/L、导弹制导参数）、美术配置（`art`：底座/炮身/炮管/火光/充能/后坐/弹丸引用）与弹丸美术库（`ProjectileArtDef`）。所有出厂定义集中在 `src/game/config.ts`：`TURRET_DEFS` 为可变注册表（内存编辑 + bump，不持久化于代码外），弹丸侧对应 `PROJECTILE_ARTS` 注册表。

### 1.2 炮塔五类（WeaponType）

代码口径：`type WeaponType = 'direct' | 'lob' | 'missile' | 'beam' | 'spray'`。类型决定弹道模型、可用参数子集与弹丸类别映射。

| type | 中文名 | 定位与弹道模型 | 可用特征参数 | 出厂代表炮塔（TURRET_DEFS） |
|---|---|---|---|---|
| `direct` | 直射 | 实弹直线飞行，按弹速推进，可穿透、可爆炸（`blastRadius>0` 时命中点波及） | projectileSpeed、accuracy、pierce、blastRadius/blastEffect | 哨戒机枪（mg，S 型双管轮流 6 连发）、加农炮（M）、大型双联加农炮（L 双管齐射） |
| `lob` | 抛射 | 抛物线弹道，按飞行时间插值，落点爆炸 + 燃烧 | projectileSpeed（缺省 60）、blastRadius（落点爆炸缺省 15m）、blastEffect.burn | 榴弹抛射炮（lob，M 型，爆炸 20m + 命中燃烧） |
| `missile` | 导弹 | 自驱动弹道：初速→加速爬升→（可选延迟制导/蛇形/燃尽滑行/集束分裂），可制导追踪、可对空 | guided、guideDelay/guideDecel、missileInitSpeed/Accel/MaxSpeed/TurnMax/TurnAccel、missileFlightTime、missileCurve、ejectAngle、burnTime、split | 巡航导弹井（cruise，L 型非制导锁定落点）、猎手制导导弹（hunter，S 型 4 管轮流、延迟制导、可对空） |
| `beam` | 射线 | 无实体弹丸的持续光束；宽幅矩形按 tick 结算伤害，发射期间炮塔转向速度 ×0.5 削减 | beamWidth、attackDuration/dot、chargeTime、energyPerShot/energyPerSec | 磁轨光束塔（beam，持续伤害 + 充能前摇） |
| `spray` | 喷射 | 扇形火焰锥持续灼烧，无弹丸（`art.projectile` 配置不生效），按秒耗弹药 | sprayAngle、attackDuration、dot、reload、ammoPerSec | 烈焰喷射塔（spray，S 型 60° 扇形） |

> 注：不存在近战（melee）/生产（produce）炮塔类型；「生产」仅存在于堡垒内部模块（`ModuleDef.produce`）与特殊格加成类别（`SpecialBoost` 含 'produce'），不属于炮塔域。

### 1.3 弹丸/光束美术定义（ProjectileArtDef）的定位

弹丸库（`PROJECTILE_ARTS`）是与 `TURRET_DEFS` 同模式的可变注册表，承载**纯表现层**配置：弹体贴图、尾焰（trail）、爆炸（explosion）、命中（impact）与光束表现（beam），不含任何伤害/弹道数值（弹道数值在 `TurretDef`）。炮塔经 `art.projectile` 按条目 id 引用；条目缺失或不可用 → 回退几何弹丸/默认光束表现。

- 条目类别（`ProjectileArtKind`）与炮塔类型存在映射约定：`direct→bullet（实弹）`、`lob→shell（抛射）`、`missile→missile（导弹）`、`beam→ray（射线）`；类别不匹配仅黄警提示，允许跨类借用、按配置生效。
- 光束表现组（`beam`）挂在弹丸库 **ray 条目**上（仅 `kind:'ray'` 有意义）：射线类炮塔引用 ray 条目即同时获得光束分层贴图表现与命中特效；旧配置中炮塔 `art.beam` 字段读取忽略，由引用条目的 beam 组接管。解析链：`def.art?.projectile → 弹丸条目 → entry.beam`（art.ts `beamArtConfig`）。
- ray 条目不提供尾焰与爆炸编辑（hitscan 无弹道飞行）；未配置尾焰的弹丸**无任何默认尾迹**（实弹无默认曳光线，导弹喷口焰随尾焰配置门控）。
- 出厂条目：bullet_std 标准实弹（bullet）、shell_std 标准榴弹（shell）、rocket_std 标准火箭（missile）、ray_std 标准射线弹（ray，含光束表现组）、custom_ammo_1 集束导弹（missile，猎手塔挂载）、custom_ammo_2 炮弹（bullet，两门加农炮挂载）。

### 1.4 挂载/炮位/堡垒的关系（简述）

炮塔不独立存在于战场格子，而是挂载到堡垒的炮位（`Hardpoint`）上，或由场景直接放置（地面炮塔）。要点：

- 炮塔与炮位仍保留 S/M/L 槽位尺寸，`TurretDef.mount` 必须匹配炮位 `size`；尺寸只决定挂载兼容性，不再联动或表示炮塔占格。
- 挂载校验（engine.ts `mountTurret` 前置检查）：炮位存在、尺寸匹配、炮位 `types` 白名单（未配置=不限类型）包含该炮塔类型、炮位未被占用、资源足够。
- 炮位的射界（`arc` 指定视角 / `fixed` 固定视角）、炮塔素材隐藏（`hideTurretArt`）、预装炮塔（`builtIn`）和渲染层级（`zLevel`）等属单位域，详见《堡垒编辑器设计》，本文不展开。隐藏炮塔素材只影响绘制，不影响装配和战斗。

### 2.2 TurretArt（art 美术组）逐参数表

坐标系：炮塔原点固定为运行时几何中心，并与载具炮位中心重合；挂点、炮口和充能点均相对此原点，炮口朝上基准系中 x 向右为正、y 向上（沿炮口方向）为正，单位格。`anchor` 只描述炮身贴图自身的旋转轴心相对原点的位置，不再改变炮位、索敌或弹丸出生点。美术坐标空间固定 32px=1 格（与贴图设计基准一致）。校验由 art.ts `validateArt` 执行（errors 硬性错误 / warnings 提示）。

### 2.4 缺省/可选参数的行为约定（回退规则汇总）

1. **炮塔可见层缺省**：`art` 未配置，或底座/炮身/炮管/火光字段缺省、为 `'none'`、为遗留 `'geo'`、引用失效时，该层保持透明，不再从文件夹取默认贴图，也不补画程序化几何图形；各层只有显式选择且加载成功的素材才绘制。
2. **弹丸引用回退**：`art.projectile` 未配置 → 几何弹丸（曳光短线/几何圆点）与默认光束表现；引用条目不存在 → 同上回退（黄警）；类别不匹配 → 黄警但按配置生效；喷射类引用 → 不生效（黄警）。
3. **光束表现回退**：ray 条目无 beam 组或组缺省 → 贴图默认搭配（beam_glowA/beam_coreA + glow16 双端闪光 + flicker 0.15 + 滚动 96）；单层素材加载失败 → 该层回退等效程序化矩形；'none' → 显式程序化/不显示。
4. **尾焰空配置语义**：未配置 trail = 无任何默认尾迹（实弹无曳光线、导弹无喷口焰）；空配置即用户明确不要尾焰，引擎不擅自加戏。
5. **导弹可选参数链**：guided 缺省 false（常规）；guideDelay 缺省=立即制导；guideDecel 缺省/0=延迟期照常加速；missileInitSpeed 缺省 0；burnTime 缺省=全程燃烧；split 未配置或 count<2 = 不分裂（首次填入自动补默认 40°/近炸/3.2m）；missileCurve 缺省 0=直线；interceptable 缺省 true，interceptHp 缺省 1。
6. **装填与连发**：fireRate 为每轮/每次持续攻击结束后的装填时间；burst 缺省 1、burstInterval 缺省 0、barrels 缺省 1、barrelMode 缺省 salvo。
7. **持续型硬依赖**：光束/喷射必须配置 dot（引擎非空读取）；beamWidth 判定缺省 2m、sprayAngle 缺省 60°、attackDuration 缺省 1s。
8. **资源消耗与补给**：直射、抛射、导弹每实际发射 1 枚弹丸固定消耗 1 发弹药；喷射按 ammoPerSec、射线按 energyPerShot/energyPerSec 消耗。外部增减补给、功能区域和恢复模块的正向弹药恢复量统一乘以炮塔 `ammoExchangeRate`；负数扣除不换算。热量汇聚战车池，过热迟滞解除阈值 = 上限 ×0.5。
9. **遗留字段兼容**：`art.spriteSet`、弹丸 `spriteSet`、`barrels[].recoil` 为遗留字段，UI 已移除但现行代码仍按解析链/回退链读取；旧 `/sprites/` 路径前缀经 `resCompatUrl` 自动重写为 `/res/`；旧配置中的 `art.beam`、人员（crew/minCrew）、制导律（guidance）、最大角度（arc）等字段读取忽略、无害保留。
10. **索敌缺省**：tags 未配置 = 现状索敌（近堡垒优先、空军 ×0.5、无资源门控），详见第 3 章。
## 3. 索敌系统（标签式索敌）

索敌系统的职责：每座炮塔每帧从战场的目标候选集中选出一个目标，并给出炮口期望角度与开火许可。现行实现位于 `src/game/engine.ts` 的 `targetCandidates()` / `tagScore()` / `aim()` / `resourceHold()`，配置类型位于 `src/game/config.ts`（`TurretTag` / `PreferTagKey` / `ExcludeTagKey` / `ResourceTagKey` / `TurretDef.tags`）。

### 3.1 目标候选集 targetCandidates

普通单位候选由 `targetCandidates(s)` 返回；导弹候选由 `interceptableMissileTargets(s, observerFaction)` 从玩家弹丸池与统一单位弹丸池汇总。两者在 `aim()` / `enemyMountedTurretTarget()` 中进入同一次排序，阵营关系统一通过 `factionsHostile()` 判断。只有 `canInterceptMissile=true` 且武器为直射或射线时才注入导弹候选。

敌方堡垒、僚机、堡垒生产单位仍保留后续合流位置；导弹实体已完成合流，不再属于预留候选。

### 3.2 标签模型总览

标签存于单座炮塔定义 `TurretDef.tags?: TurretTag[]`，判别联合三类：

```ts
type TurretTag =
  | { kind: 'prefer'; key: PreferTagKey }                          // 软排序
  | { kind: 'exclude'; key: ExcludeTagKey }                        // 硬过滤
  | { kind: 'resource'; res: ResourceTagKey; op: 'lt' | 'gt'; value: number } // 资源门控
```

三类的语义分工：

| 类别 | 作用层 | 语义 |
| --- | --- | --- |
| prefer 软优先 | 评分（`tagScore`） | 各键贡献一个权重因子**连乘**到基准分，分数越小越优先；prefer 之间非条件、不互斥 |
| exclude 硬过滤 | 候选过滤（`aim`） | 命中的目标直接从候选集中剔除，不参与评分 |
| resource 资源门控 | 开火开关（`resourceHold`） | 条件成立即**禁止开火**（硬切换，见 §3.5） |

组合规则：所有 exclude 过滤与 resource 门控必须**全部通过（AND）**才允许开火；prefer 标签只影响"先打谁"，不影响"打不打"。

### 3.3 评分公式（tagScore）

`aim()` 对每个通过过滤的候选调用 `tagScore(s, c, e, def)`（`c` 为炮塔中心），取**分数最小**者为目标（`score < bestScore` 即替换）。

**基准分**：

```
基准分 = 含 nearTurret 偏好标签 ? 目标距炮塔中心 hypot(e.x - c.x, e.y - c.y)
                                 : 目标距堡垒中心 distToFortress(s, e)
```

即默认基准是"近堡垒优先"；配置 `nearTurret` 偏好后改为"近炮塔优先"。`nearFortress` / `nearTurret` 两个偏好不再产生额外因子，只体现在基准分的选择上。

**空中单位系数（兼容默认）**：当 prefer 标签中**没有** `air` 或 `ground` 键时，空中单位基准分 ×0.5（即优先拦截空军）；一旦配置了 `air` 或 `ground` 偏好，该默认系数不再叠加，由偏好因子接管。

**各 prefer 键的权重因子**（满足条件才乘，连乘到基准分）：

| 键 | 因子公式（代码表达式） | 效果 |
| --- | --- | --- |
| `air` | 空中单位：`score *= 0.5` | 空中优先 |
| `ground` | 地面单位：`score *= 0.5` | 地面优先 |
| `hpMax` | `score *= 1 / (1 + e.hp / 100)` | 血最多优先（当前血越高因子越小） |
| `hpMin` | `score *= 1 + e.hp / 100` | 血最少优先（当前血越高因子越大） |
| `sizeBig` | `score *= 1 / (1 + ed.size / 0.35)` | 大体型优先（体型 `size` 越大因子越小） |
| `sizeSmall` | `score *= 1 + ed.size / 0.35` | 小体型优先（体型越大因子越大） |
| `nearFortress` | 无因子，基准分 = `distToFortress(s, e)` | 近堡垒优先（即默认基准） |
| `nearTurret` | 无因子，基准分改为距炮塔 | 近炮塔优先 |
| `missile` | 导弹目标：`score *= 0.2` | 导弹优先；普通单位分数不变 |

**候选过滤（aim 内的硬条件，先于评分）**：

1. `hp <= 0` 跳过；
2. 空/地适配：目标为空中且 `def.canAir === false` 跳过；目标为地面且 `def.canGround === false` 跳过；
3. exclude 标签：目标为空中且存在 `exclude:air` 跳过；目标为地面且存在 `exclude:ground` 跳过；导弹目标存在 `exclude:missile` 时跳过；
4. 射程区间：目标距炮塔 `distM = hypot(dx, dy) * M_PER_CELL`（米，M_PER_CELL = 3.2），`distM < rangeMin` 或 `distM > rangeMax * (1 + turretRangeBonus(s))` 跳过——射程上限含火控雷达模块增益（增益池按炮塔数摊薄）。

### 3.4 exclude 硬过滤键

`ExcludeTagKey = 'air' | 'ground' | 'wingman' | 'missile' | 'fortress' | 'spawned'`。现行生效键为 `air`（不打空中）、`ground`（不打地面）、`missile`（不攻击导弹）；其余为预留键（见 §3.7）。过滤在候选循环中执行，命中即跳过，被剔除目标不参与评分排序。

### 3.5 resource 资源门控（resourceHold）

资源门控是**开火硬开关**，在 `updateTurretBody()` 中紧邻堡垒过热检查统一拦截。

**百分比口径**（阈值 `value` 均为占上限的百分比 0–100）：

| 资源键 | 当前百分比（代码表达式） | 上限口径 |
| --- | --- | --- |
| `ammo` 弹药 | `ammoCapacity > 0 ? turret.ammo / ammoCapacity * 100 : 100` | 当前炮塔定义的 `ammoCapacity` |
| `energy` 能量 | `energyCapacity > 0 ? turret.energy / energyCapacity * 100 : 100` | 当前炮塔定义的 `energyCapacity` |
| `heat` 热量 | `heatCap > 0 ? s.fortress.heat / heatCap * 100 : 0` | 堡垒热量池上限 `fortressDef(s).heatCap` |
| `defense` 防御 | `maxHp > 0 ? s.fortress.hp / s.fortress.maxHp * 100 : 100` | 堡垒耐久上限 |

**判定语义**：遍历全部 resource 标签，`op === 'lt'` 时 `v < value` 即成立，`op === 'gt'` 时 `v > value` 即成立；**任一**标签条件成立 → `resourceHold()` 返回 true → 禁止开火（例如"弹药低于 30% 停火"配 `{ res:'ammo', op:'lt', value:30 }`，"热量高于 80% 停火"配 `{ res:'heat', op:'gt', value:80 }`）。未配置任何 resource 标签时恒返回 false（无门控）。

**触发即停火的硬切换**：门控成立当 tick 直接执行 `t.firing = false; t.burstLeft = 0; t.chargeLeft = 0; return`——持续型武器（光束/喷射）立即中断、连发中止、充能取消，与堡垒过热同一条路径；条件恢复成立后按正常流程重新索敌/充能起射。

### 3.6 零标签默认行为

`tags` 未配置（undefined/空数组）时的行为：

- 无 exclude 过滤 → 空/地适配仅由 `canAir` / `canGround` 决定；
- 无 prefer 因子 → 评分 = `distToFortress`（近堡垒优先），空中单位 ×0.5（兼容默认系数生效）；
- 无 resource 门控 → 永不因资源阈值停火（仅受堡垒过热与弹药/电量实际耗尽的约束）。

即：**零标签 = 近堡垒优先 + 空军 ×0.5 + 无资源门控**。

### 3.7 预留键位

`PreferTagKey` 与 `ExcludeTagKey` 中仍未激活的预留键为：`fortress`（敌方堡垒）、`wingman`（僚机）、`spawned`（堡垒生产单位）。`missile` 已正式激活。

现行行为：

- 评分与过滤：上述三个剩余键暂不产生因子，也不剔除现行实体；
- 候选集：对应实体尚未正式并入炮塔目标协议。

这些键是**类型位预留**：待对应实体上线后激活，编辑器当前不向用户开放。导弹优先/不攻击导弹已经在标签编辑器开放。

## 4. 开火行为与资源

本章描述炮塔从索敌到击发的完整行为链路，以及弹药/电量/热量三类资源的消耗与回复。全部语义以 `src/game/engine.ts` 的 `updateTurretBody()`（及 `aim()` / `fireGunShot()` / `addFortressHeat()` / `coolFortress()` / `tick()` 资源回复段）为准。

### 4.1 开火流程总览

`updateTurretBody(s, t, dt)` 每帧按固定顺序推进（效率系数 `factor` 恒为 1）：

1. **表现衰减**：导弹复挂动画计时 `rackAnim` 每 tick 无条件衰减；
2. **导弹复挂**（仅导弹塔）：一轮打空（`burstLeft === 0`）且未满挂时，每隔 `x = fireRate / (burst + 1)` 秒 `rackLeft + 1` 至满挂（`full = max(1, burst ?? 1)`）；轮中（含中断暂停）与满挂不复挂；复挂与索敌无关；
3. **堡垒过热检查**：`s.fortress.overheated` 为真 → `firing=false, burstLeft=0, chargeLeft=0` 并返回（全炮塔停火，解除由散热迟滞控制，见 §4.6）；
4. **资源门控检查**：`resourceHold()` 成立 → 同上硬切换停火（见 §3.5）；
5. **射线维持电量**：`type:'beam'` 炮塔配置了 `energyPerSec` 时，每帧扣 `energyPerSec * dt`；电量不足则清零、`firing=false` 返回；
6. **冷却推进**：`cooldown -= dt`；
7. **索敌与转向**：调用 `aim()`（持续光束发射期间转速 ×0.5，见 §4.7）选目标、转炮、给出 `canFire`；
8. **充能前摇**（配置了 `chargeTime` 时，见 §4.3）；
9. **击发**：持续型（光束/喷射）走状态机（§4.4）；直射/抛射/导弹走"轮 + 连发"流程（§4.2）。

整体节奏即：**索敌 → 转向对准 → （充能）→ 开火 → 冷却/装填**，任一环不满足即停在本环节等待或中止。

### 4.2 轮与连发（burst，实弹类）

适用类型：直射（direct）、抛射（lob）、导弹（missile）。

**术语**：`fireRate` 语义为 **s/轮**（每轮射击的间隔秒数，越小射得越快）；一轮含 `burst` 次击发，相邻击发间隔 `burstInterval` 秒。

**流程**：

- 空闲态（`burstLeft === 0`）：需目标存在、`canFire` 为真、`cooldown <= 0`，且当前炮塔至少有 1 发弹药，才进入新一轮：`burstLeft = max(1, burst ?? 1)`，`burstTimer = 0`（当 tick 立即首发）；
- 轮内（`burstLeft > 0`）：`burstTimer -= dt`，计时未到则等待；到点后若目标丢失或 `canFire` 不成立（移出射程/射界），`burstLeft = 0` **中止本轮**；否则执行一次击发（§4.5 多管规则），按实际弹丸数扣除 `t.ammo -= shots`，产热 `addFortressHeat(s, heatPerShot * shots)`，导弹塔同时 `rackLeft -= shots`；随后 `burstLeft--`、`burstTimer = burstInterval ?? 0`；
- 击发后若本次产热使堡垒过热：中断连发（`burstLeft = 0, cooldown = 0`）；
- 本轮打完（`burstLeft === 0`）：`cooldown = fireRate`（s/轮语义），进入冷却等待下一轮。

资源不足（弹药/电量低于本次击发需求）时直接中止本轮（`burstLeft = 0`），恢复后重新走整轮流程。

### 4.3 充能前摇（chargeTime）

配置了 `chargeTime > 0` 的炮塔，每次开火周期起射前先充能 `chargeTime` 秒（实弹类每轮一次；持续型每次 attackDuration 周期一次；轮内连发/齐射/轮流**不重复充能**）。

状态机（`chargeLeft` 为剩余秒数）：

- 空闲且满足起射条件（目标存在、`canFire`、`cooldown <= 0`，持续型需 `!firing`、实弹类需 `burstLeft <= 0`）→ 进入充能：`chargeLeft = chargeTime`；
- 充能中（`chargeLeft > 0`）：每帧 `chargeLeft -= dt`；此期间**不射击、不产热、不耗弹药/电量**（视为"不射击"，堡垒可自然散热）；目标丢失或移出射程射界（`!target || !canFire`）→ 取消充能（`chargeLeft = 0`），重新索敌后需重新充能；
- **末帧滞留**：充能最后一帧不计入充能时间——`chargeLeft` 计到 0 后进入负值滞留段 `(-CHARGE_LAST_HOLD, 0)`（`CHARGE_LAST_HOLD = 0.05` 秒，精确落零以 `-1e-9` 兜底），滞留结束（`chargeLeft <= -0.05`）当 tick 起正常开火。

### 4.4 持续型武器（光束 / 喷射）

适用类型：喷射（spray）与射线（beam）。射线炮塔固定走持续光束流程。

**状态机**：

- 起射（非 firing 态）：需目标存在、`canFire`、`cooldown <= 0`；预检资源——光束 `energyPerShot` 不足不起射，喷射配置了 `ammoPerSec` 且 `ammo <= 0` 不起射；通过则光束先扣 `energyPerShot`（发射电量），`firing = true`、`firingLeft = attackDuration ?? 1`、`tickTimer = 0`；
- 持续中（firing 态）：
  - 喷射按 `ammoPerSec * dt` 逐帧消耗当前炮塔弹药，不足时清零停射并进入装填；
  - DoT 结算：`tickTimer -= dt`，到点后按 `dot.interval` 周期结算一次伤害（光束 `beamTick` / 喷射 `sprayTick`），`tickTimer += dot.interval`；光束起射伸展期（长度未达全长/阻挡点）不消费计时器，伸展到位当帧立即结算首次伤害；
  - `firingLeft -= dt`，耗尽即本次持续结束：`firing = false`，`cooldown = fireRate`。

持续光束起射后以 `BEAM_ON_SPEED = 307.2 m/s` 从炮口伸展到全长（32m 射程约 0.10s）；停火（持续结束/目标丢失/资源中断/过热/门控）触发 0.25s（`BEAM_FADE`）收窄渐隐的消退段。

### 4.5 多联炮管（barrels / barrelMode）

`barrels` 为逻辑炮管数（默认 1 单管），多管时由 `barrelMode` 决定击发方式（缺省 `'salvo'`），持续型光束/喷射不适用：

- **齐射 salvo**：每次击发**全部炮管各射 1 枚**（`shots = nBarrels`），弹药/热量/电量均按实际弹丸数（×shots）结算；
- **轮流 sequential**：每次击发仅 1 枚，从 `barrelIdx` 炮管射出并轮转 `barrelIdx = (barrelIdx + 1) % nBarrels`；连发间隔即相邻两管的发射间隔，`barrelIdx` **跨轮不重置**。

弹丸出生点：导弹取挂载位（待发弹视觉位置，槽位对应该管当前枚数 -1，与展示消耗一致）；实弹/抛射取炮口点 `muzzlePos`。直射弹丸出生点沿弹道反向预偏一个 tick 行程（`traveled` 负初始化），首帧渲染恰好位于炮口。

### 4.6 资源消耗与回复

弹药与能量为**每座玩家炮塔独立资源池**；热量仍为玩家当前战车的汇聚池。非玩家单位（敌方、友方及 AI 固定炮塔）默认无限弹药、无限能量，但仍正常产热并受过热影响。

战斗 HUD 为每座玩家炮塔生成一个独立的自动开火按钮，并显示该炮塔自己的弹药或能量竖条。关闭按钮后，该炮塔立即停止索敌与开火、清除当前目标，并按自身转速回到炮位原始相对朝向：固定视角回固定角、指定视角回视界中心、全视角回车头方向，地面炮塔回世界上方；重新开启后恢复正常状态机。旧运行时数据未保存开关时一律视为开启，非玩家炮塔不受玩家 HUD 开关影响。

**弹药**：

- 池：安装或新建炮塔时按 `ammoCapacity` 满载；旧实弹/喷射配置缺少容量时迁移为 100，旧 `ammoPerShot` 字段会删除；
- 默认不会自然恢复；当前玩家单位安装了弹药恢复模块时，每座玩家炮塔按 `ammoRegen * dt * ammoExchangeRate` 独立恢复并钳制到自身容量；
- 事件“增减补给”和“功能区域”的正向弹药补给同样乘以该炮塔的 `ammoExchangeRate`；例如汇率 0.5 时输入 2 单位仅恢复 1 发。负数扣除保持原值，不经过汇率；
- 消耗：直射、抛射、导弹按实际发射弹丸数扣除，固定每枚 1 发；喷射按 `ammoPerSec` 每秒；只影响实际开火的炮塔，耗尽/不足即停射。

**能量**：

- 池：安装或新建炮塔时按 `energyCapacity` 满载；旧配置若有 `energyPerShot`/`energyPerSec` 而缺少容量，则迁移为 100；
- 默认不会自然恢复；当前玩家单位安装了能量恢复模块时，每座玩家炮塔按 `energyRegen * dt` 独立恢复并钳制到自身容量；
- 消耗：光束类按 `energyPerShot` 每次起射扣除一次，并按 `energyPerSec` 每秒维持；只影响当前光束炮塔，不足即中断。

**热量（堡垒热量池）**：

- 产热：每次击发 `addFortressHeat(s, heatPerShot * shots)` 汇聚到堡垒热量池，封顶 `heatCap`；`heat >= heatCap` 即 `overheated = true`——**全炮塔停火**；
- 散热：玩家战车使用“游戏参数 → 战斗参数 → 自然散热值”作为基础散热，再叠加散热器模块冷却池（散热器全额直连、不按炮塔数摊薄）；每 tick `heat = max(0, heat - cooling * dt)`，射击中、过热中均持续散热。修改热量上限不会同比改变自然散热或炮塔产热；非玩家单位仍读取各自单位模板的自然散热。
- 过热解除迟滞：过热状态持续至 `heat <= heatCap * OVERHEAT_RESUME`（`OVERHEAT_RESUME = 0.5`）才解除，即攒满停火、降到半池复射；
- 出厂默认堡垒 `heatCap = 200`、`heatDissipation = 10` 点/s。

### 4.7 炮塔转向与跟随

**基角**：挂载炮塔的基角随船头朝向 `s.fortress.heading`，地面炮塔基角恒 0（朝上）。

**转速**：`rotateSpeed` 度/秒（`rot = rotateSpeed * factor * DEG`，`factor` 恒 1），每帧转向步长 `min(需转角度, rot * dt)`。光束发射期间转速削减 50%（`BEAM_TURN_FACTOR = 0.5`）。

**射角（aimCone）**：以炮口方向为中心的总角度，免转瞄准锥半宽 `coneR = max(aimCone / 2, 4°)`（最小 4°）。目标在射角内时**无需转炮**直接视为对准；偏离射角时才旋转，且只转到目标进入射角即停（步长 `min(|diff| - coneR, rot * dt)`，炮口方向恒为射角中心）。开火条件 `aligned = |wrapAngle(目标方位 - 炮口角)| <= coneR`。

**视角约束**（挂载炮塔由炮位配置，三模式）：

- 固定视角：期望角恒为固定角，炮口不追踪目标；仅当目标自行进入射角锥时开火；
- 指定视角（视界区间）：目标须在视界区间内方可开火（`inArc`），期望角钳制进视界；
- 全视角：360° 自由旋转（炮塔级最大角度参数已取消）。

`canFire = inArc && aligned`——视界外或未对准不可射击。

**无目标回中**：无目标时炮口按转速缓慢转回休息角——固定视角回固定角，有视界回视界中点，否则回基角。

### 4.8 射击精度（accuracy 散布）

`accuracy` 为命中偏差半径（米）。散布取样（`accuracyOffset`）：

```
a = eventRandom(eventId, 0) * TAU
r = sqrt(eventRandom(eventId, 1)) * m2c(accuracy)  // 开平方保证圆盘内均匀
偏移 = (cos(a) * r, sin(a) * r)
```

即以瞄准点为圆心、`accuracy` 为半径的圆盘内**均匀随机**取命中点。随机样本由投射物事件 ID 与独立流编号派生，因此相同状态和输入必得相同结果，不依赖进程级 `Math.random`。各类型应用口径：

- 直射（direct）：瞄准点 = 目标位置 + 散布偏移，弹丸沿炮口→偏移点方向直线飞行；
- 抛射（lob）：落点 = 目标位置 + 散布偏移，抛体飞向该落点爆炸；
- 导弹（missile）：非制导发射瞬间锁定落点 = 目标位置 + 散布偏移（之后不再修正）；制导弹不加散布（追踪目标）；
- 光束 / 喷射：不使用 `accuracy`，按光束宽幅或喷射扇形范围结算。
## 5. 直射炮（direct）

直射炮发射实弹（bullet），弹丸沿直线匀速飞行，命中判定逐 tick 进行。弹道参数全部在 `TurretDef` 上配置，弹丸表现经 `art.projectile` 引用弹丸库条目（见第 7 章）。

### 5.1 实弹弹道

**弹速与飞行**

- `projectileSpeed`（m/s，缺省 200）：弹丸每 tick 前进 `弹速 × dt`，全程匀速，无加速/减速/下坠。
- 出生点：配置了 `art.barrels` 挂点表时取对应炮管的 `muzzle` 挂点（随炮塔当前角度换算到世界坐标）；未配置时由统一挂点规则自动生成，单管炮口为 `[0, 0.35]`，多管沿垂直炮口方向均布且同样前伸 0.35 格。预览标记、弹丸出生点和火光事件必须共用这一坐标来源。
- 出生点沿弹道**反向预偏一个 tick 行程**（v·dt）：开火（tick 步骤 4）先于弹道推进（步骤 5），同 tick 内弹丸会被立刻前移 v·dt，预偏后首个可见帧恰好位于炮口，弹速再快也不会出现"出生即离口"的脱节；`traveled` 相应负初始化，射程消亡口径不变。

**精度散布**

- `accuracy`（m，命中偏差半径）：以目标位置为圆心、accuracy 为半径在圆盘内均匀随机取一个命中点（`sqrt(random)` 半径采样保证面密度均匀），弹丸朝该点飞行。accuracy 越大散布越开；0 = 指哪打哪。
- 散布只在开火瞬间决定弹道方向，飞行途中不再修正。

**射程**

- `rangeMin` / `rangeMax`（m）：索敌阶段即生效——目标距离在区间外不可瞄准（近距死区 + 远距上限）。`rangeMax` 受火控雷达射程增益影响（增益池按炮塔数摊薄）。
- 弹丸自身射程 `maxTravel = rangeMax + 3.2m`（一格余量，防止恰好贴边目标脱漏）；`traveled ≥ maxTravel` 时消亡。弹丸允许越过战场边界继续飞行，以支持场外飞行单位正常开火并让弹丸重新进入战场；场外耗尽射程的直射弹不生成地面弹坑。

**穿透 pierce**

- `pierce: { count, decay }`：一发弹最多作用 `1 + count` 个目标（count=0 = 命中第一个目标即消失）。
- 命中判定为**线段-圆形**：每 tick 以上一帧位置→当前位置的线段对每个存活敌人做最近点判定，命中半径 = 敌人体型 + 0.06 格；空军目标在炮塔 `canAir=false` 时不参与判定。
- 同一 tick 命中的多个目标按沿程先后排序结算；已命中的敌人记录在 `hitIds` 中不重复命中。第 1 个目标吃 100% 伤害，之后每穿透一个目标伤害 ×`(1 − decay)^已命中数`；命中数达到上限弹丸消失。

**命中与命中事件**

- 命中敌人：结算伤害（含等级倍率与穿透衰减）；若炮塔配置了 `art.projectile`，在敌人身体视觉中心（脚底锚点上方 size×身高系数处，加每次不同的确定性抖动）推一条 impact 事件（ttl 0.15s），由弹丸库条目的命中参数驱动碎屑特效；未配置弹丸条目则不产生事件、无任何命中特效。
- 命中阻挡弹道的物体：弹丸消失不穿透，物体有耐久则扣耐久（归零摧毁）。
- 配置了爆炸（`blastRadius > 0`）的直射弹在命中敌人或物体时同时触发爆炸：直击目标吃直击+爆炸，波及目标只吃爆炸（爆炸伤害基底 0，附加/燃烧由 `blastEffect` 提供），遮挡豁免与波及口径与榴弹爆炸一致。

### 5.2 点射/连发行为在直射上的表现

直射走"**轮 + 连发**"模型（`fireRate` / `burst` / `burstInterval` / `barrels` / `barrelMode`）：

- `fireRate`（s/轮）：每轮射击的间隔秒数，越小射得越快。一轮打完后进入该时长的冷却。
- `burst`（连发数，缺省 1）+ `burstInterval`（s）：一轮内连续击发 burst 次，相邻击发间隔 burstInterval。
- 多管 `barrels` + `barrelMode`：
  - `salvo` 齐射（多管缺省）：每次击发全部炮管各射 1 枚，弹药/热量/电量按实际弹丸数结算；
  - `sequential` 轮流：每次击发仅当前管射 1 枚，之后轮转下一管——连发间隔即相邻两管的发射间隔，炮管序号跨轮不重置。
- 中断规则：轮中目标丢失/移出射程射界、资源（弹药）不足、堡垒过热，均立即中止本轮剩余连发；过热中断额外清零冷却。
- 配置了充能时间 `chargeTime` 时，每轮起射前先充能（充能期间不射击、不涨热、不耗资源）；目标在充能期间丢失则取消充能、重新索敌后重新充能。轮内连发/齐射不重复充能。
- 每发产热 `heatPerShot × 实际弹丸数`，汇聚到战车热量池；弹药固定按实际弹丸数每枚扣 1。

### 5.3 弹丸视觉（概述）

- **弹体**：经 `art.projectile` 引用弹丸库 bullet 条目；有条目且贴图就绪时按**原图尺寸**绘制（1 贴图像素 = 1 画布像素 × 缩放，宽高比保持），随飞行航向旋转。无条目/无贴图/`'none'` 显式无贴图时回退几何弹丸（米黄描边圆点）。
- **尾焰/曳光**：尾部表现完全由弹丸条目 `trail` 尾焰组驱动（程序化粒子，模板+参数，见第 7 章）；**不配置尾焰即飞行时只有弹体、无任何默认尾迹**——引擎不提供任何程序化曳光回退，也不在开火瞬间向目标拉发射直线。
- 贴图、尾焰模板、颜色渐变等美术细节见第 11 章。

### 5.4 抛射弹道与落点视觉

- 抛射炮的命中坐标、飞行时间和爆炸结算保持原有规则；视觉层只根据起点、落点与标准化飞行进度计算抬升，不改写战斗参数。
- 弹体水平位置仍在起点与落点间线性插值；视觉高度使用对称抛物线 `4t(1-t)×弧高`。弧高随射程增加并限制在 0.8～4 格，近距离仍有可读的小弧线，远距离不会无限抬高。
- 弹体在最高点最多放大至 1.18 倍；地面投影始终沿真实水平轨迹移动，并随高度缩小、变淡，使玩家可区分地面落点与空中弹体。
- 飞行最后 35% 显示逐渐收拢的落点圈，圆心严格使用当前弹丸的真实 `tx/ty`；命中时落点圈、弹体和爆炸使用同一坐标，不产生视觉假落点。
- 玩家炮塔、敌方/友方车载炮塔与普通单位抛射攻击共用同一个弧线视觉函数。

## 6. 导弹（missile）

导弹发射后自驱动飞行：有速度、转向速率等状态，逐 tick 积分推进。与直射/抛射最大的不同是**制导与发动机模型**——导弹可以追踪目标、有燃烧时间、有飞行寿命。

### 6.1 制导模式与锁定行为

`guided` 与 `guideDelay` 组合出三种模式：

| 模式 | 配置 | 行为 |
|---|---|---|
| 常规（非制导） | `guided: false` | 发射瞬间按精度散布锁定**落点坐标**，之后不再修正；飞行中撞上任何敌人即在其处爆炸（沿途撞击）；到达锁定点即爆炸（目标移动不改变落点） |
| 制导 | `guided: true` | 出生即锁定目标（真锁定 `targetId`），全程前置量追踪 |
| 延迟制导 | `guided: true` + `guideDelay > 0`（0.05~2s） | 发射航向 = 炮塔方向 + `ejectAngle` 出膛偏角（度，缺省 0；可做二维侧抛），延迟期内沿该航向直飞——不追踪、不触发锁定点爆炸；延迟归零自动开启制导追踪 |

**真锁定与重锁**：制导弹出生时记录目标 `targetId`，此后只认该目标。**仅当目标死亡/不存在时才重锁**（`retargetMissile`）：候选按空/地规则过滤后，优先取"剩余飞行时间内可达"者（距离 ÷ 极速 ≤ 剩余飞行时间 × 0.9 机动余量）中最近者；无可达候选则取全体最近者（允许追不上，之后由飞行寿命收尾）。重锁时近炸引信基线与前置量采样基线同步重置。完全无候选时保持直飞最后已知位置。

**脱靶不丢锁**：制导导弹全程保持追踪——即使越过目标、转向能力不足也不失去锁定，每 tick 以转向能力上限持续向目标方向收敛，转向不足就盘旋回绕继续追。收尾由三条路径承担：

1. **近炸引信**：与目标距离由减转增（通过最近点）且仍在近炸半径内（`blastRadius` 折算 + 0.6 格）时擦爆；直接命中（距离 ≤ 敌人体型 + 0.45 格）同样爆炸。
2. **飞行时间** `missileFlightTime`（秒，未配置 = 不限）：耗尽未命中则进入 0.5s 淡出——停止制导、惯性直飞、不再命中/爆炸，淡出结束移除。
3. **射程终点**：`traveled ≥ rangeMax × 1.3` 就地爆炸；飞出战场边界不会提前消失，仍可跟随场外飞行目标或重新进入战场。

**前置量制导**：制导恒为前置量（lead）追踪——按目标速度预估拦截点。敌人无速度字段，由导弹侧按相邻 tick 目标位移 ÷ dt 采样估算；预估命中时间 = 距离 ÷ 当前弹速（封顶 2s 防远距过冲），迭代 1 次。首帧无采样基线时退化为直飞目标当前位置。转向机构：`turnRate` 从 0 按 `missileTurnAccel`（度/s²）爬升，上限 `missileTurnMax`（度/s）。

**飞行曲线**：`missileCurve`（0~100，缺省 0 = 直线）在基础航向（制导追踪/非制导锁定航向）上叠加余弦航向偏置——偏置 = (curve/100) × 90° × cos(2π × 0.8Hz × 弹龄 + 相位），相位每发随机，往复摆动非单边扭转；weave 为气动摆动，不占用转向机构角速度，也不改变命中/过期判定（均按弹体实际位置结算）；贴图与喷口跟随同一可视航向。

**阻挡物体**：导弹飞行途中不与阻挡弹道的物体碰撞（一般可越过）；仅当发射瞬间"炮口→目标"线段穿过阻挡物体、且目标格紧邻物体后方（沿线格距 ≤ 物体高度 `height`）时，导弹退化为非制导直飞物体位置爆炸并结算物体耐久。

### 6.2 发动机与速度模型

- **初速度** `missileInitSpeed`（m/s，缺省 0 = 从静止加速）：发射瞬间的标量速度；可大于极速，超出后不再加速仅维持。
- **加速**：燃烧期内按 `missileAccel`（m/s²）加速，上限 `missileMaxSpeed`（缺省 100）。
- **延迟减速** `guideDecel`（m/s²，缺省 0 = 延迟期照常加速）：仅延迟制导期内生效，速度减到 0 为止（悬停式垂发）。
- **垂直发射素材**：启用垂发后，当前 `projectileAsset` 自动按固定横向 7 帧处理；第 1 帧为全垂直、第 7 帧为正常飞行、第 2～6 帧为转向过程。编辑器不再提供独立“转向贴图”，垂发结束后持续显示第 7 帧。垂发转向期内制导、重索敌、转向、加速与燃烧参数已经生效，但弹体停留在发射点且不参与碰撞；`missileFlightTime` 从离开发射阶段后才开始扣减。配置了烟尾时，烟尾从垂发离架第一帧开始生成；不再额外生成独立的垂发发射烟尘。玩家、友方与敌方导弹共用同一表现。
- **燃烧时间** `burnTime`（秒，未配置 = 全程燃烧）：期内正常加速；燃尽后惯性滑行——不再加速，渲染侧同步熄灭主尾焰/烟尾/喷口焰。
- **点火时刻**：弹龄计时基准 `igniteAtT` = 出生时的制导延迟秒数（无延迟 = 0 = 出生即点火）。点火后 1s 内主尾焰为**大力喷射**（发射速率 ×3→×1、尺寸 ×1.6→×1 线性回落），之后转常规尾焰；大力喷射是发动机点火行为，**仅导弹生效**，实弹/抛射从出生即常态尾焰。

### 6.3 发射架/挂架（rack）

导弹塔有"待发弹挂载"表现与装填节奏（`art.rack` + 引擎 rackLeft 状态）：

- `art.rack`：`show`（默认 true）控制挂载显示开关；`dx`/`dy` 为挂载点相对炮管挂点的偏移（格，默认 0 / 0.12）。
- 待发弹余量 `rackLeft` 初始满挂 = `burst`；逐发 −1、齐射 −N；多管时余量均分到各管展示（轮流模式当前管优先消耗先空）。
- **逐枚复挂**：一轮打空后启动计时，每隔 `fireRate / (burst + 1)` 秒复挂 1 枚直至满挂；轮中（含中断暂停）与满挂不复挂，复挂与索敌无关。每枚复挂播 0.25s 渐显推入动画（仅最新一枚）。
- 导弹**出生点 = 挂载位**（待发弹的视觉位置），而非炮口点；出生即按当前航向与初速起飞。

### 6.4 烟尾与喷口焰（概述）

- **烟尾**（`trail.smoke` 子组，组在=生效）：与主尾焰并行的第二股粒子流——烟团尺寸为主尾焰 1.6 倍，初速 = 弹速 ×0.15 少量惯性 + 横向弥散，前 40% 寿命膨胀扩散、之后尺寸冻结并渐隐至消失，非加法渲染。参数：速率（缺省 20 粒/s）、寿命（秒，缺省 3；不受燃烧时间限制——烟可比发动机工作更久地存留）、颜色（缺省浅灰 #9A958E）、**持续**（秒，可选）：普通弹丸从点火时刻、垂发导弹从离架首帧计算烟尾喷射窗口，结束即停喷（已有烟团自然消散）；窗口超过引用炮塔燃烧时间时按燃烧时间钳制，缺省 = 整个燃烧期。
- **喷口焰**：导弹尾部引擎喷口高亮（加法混合、亮度闪烁），随尾焰配置门控——配置了尾焰才画；未点火（延迟期）/燃尽滑行期不画。
- **发动机门控**：普通弹丸未点火（制导延迟期）时，主尾焰、烟尾、喷口焰全部熄灭；垂发导弹是例外，配置烟尾后会从垂发首帧开始喷烟，但主尾焰和喷口焰仍按点火门控。燃尽后全部停止继续发射，已有烟团自然消散。
- 美术细节见第 11 章。

### 6.5 载体速度继承

堡垒挂载炮塔（有 `hardpointId`）发射的导弹，**出生速度向量 += 堡垒移动速度**：出生瞬间一次性合成（堡垒速度 格/s 换算 m/s 后向量相加），合成结果折回"航向 + 标量初速"（合成恰好抵消归零时保持原航向）。移动中开火的导弹因此与炮口/挂架不脱节。点火制导后导弹完全自驱动，与常规一致；地面炮塔不继承。

### 6.6 集束分裂（split）

`split: { count, spread, at, range? }` 真集束分裂：

- 触发：`at: 'proximity'` = 制导弹距目标 ≤ `range` 米（缺省 3.2，即 1 格）；`at: 'burnout'` = 燃烧时间耗尽。
- 母弹裂为 `count` 颗扇形子弹（±spread/2 对称展开），伤害均分，继承制导状态/锁定目标/剩余飞行时间/弹龄；weave 相位随扇角错开，避免子弹叠摆成一束。
- 子弹带 `splitDone` 标记不再二次分裂；子弹出生即点火（点火时刻 = 分裂时刻弹龄，大力喷射/烟尾持续窗口按分裂时刻起算）。
- 分裂瞬间在母弹位置产生一次小型碎裂闪光（impact 事件），母弹随即移除。

### 6.7 导弹拦截

- **配置入口**：导弹弹丸条目提供“可拦截”和“拦截耐久”；炮塔提供“拦截导弹”。旧导弹未写字段时按可拦截、1 点耐久兼容。
- **支持武器**：首版仅直射、脉冲射线与持续光束。抛射、喷射及导弹对导弹不参与拦截。
- **统一阵营**：玩家、友方、敌方、中立敌对炮塔都从两套历史弹丸池汇总为同一种 `InterceptableMissileTarget`，只攻击 `factionsHostile()` 判定为敌对的导弹。
- **索敌排序**：默认与普通单位共同竞争目标；“导弹优先”给导弹分数乘 0.2，“不攻击导弹”直接过滤。炮塔没有开启拦截能力时，即使配置导弹优先也不会出现导弹候选。
- **提前量与碰撞**：直射武器按导弹当前速度求一次封顶 2 秒的拦截提前量；弹丸推进使用线段—圆连续碰撞，逻辑半径暂统一为 0.18 格，避免高速弹丸单帧穿过小导弹。
- **伤害与空爆**：命中只削减独立拦截耐久，不显示血条。耐久归零时导弹标记移除并播放小型空爆；不调用原弹头的爆炸、燃烧或范围伤害。未击毁时只播放命中效果并继续飞行。
- **集束导弹**：母弹可被拦截；若先分裂，则每颗子弹都是独立目标并取得该弹丸条目的完整拦截耐久，不继承母弹残余耐久。

### 6.8 与直射的关键差异

| 维度 | 直射（bullet） | 导弹（missile） |
|---|---|---|
| 弹道 | 直线匀速，方向在开火瞬间确定 | 自驱动：初速/加速/极速/延迟减速/燃尽滑行 |
| 命中方式 | 线段扫描 + 穿透多目标，单体伤害逐穿衰减 | 单点爆炸（blastRadius 范围伤害），无穿透 |
| 目标关系 | 无锁定概念，散布决定弹着 | 真锁定 targetId，目标死亡才重锁，脱靶不丢锁 |
| 精度散布 | 每发按 accuracy 散布 | 制导不受影响；非制导仅影响锁定落点 |
| 收尾 | 射程（rangeMax+3.2m）/出界即消亡，无爆炸 | 射程终点（rangeMax×1.3）就地爆炸；飞行时间耗尽淡出 |
| 阻挡物体 | 撞上即消失（扣耐久/可触发爆炸） | 一般越过；仅发射时目标紧邻物体后方才被挡 |
| 出生点 | 炮口挂点（反向预偏一个 tick 行程） | 挂载位（待发弹位置），继承堡垒移动速度 |
| 发射节奏 | 轮+连发即全部 | 额外有挂架余量/逐枚复挂表现 |
| 尾部表现 | 尾焰粒子（配置驱动，无默认尾迹） | 尾焰 + 烟尾 + 喷口焰 + 点火大力喷射，受发动机门控 |

## 7. 弹丸系统与弹丸库

### 7.1 弹丸库的结构与定位

弹丸库（`PROJECTILE_ARTS: ProjectileArtDef[]`）是全部炮塔共享的**弹丸美术/特效统一注册表**。炮塔经 `art.projectile` 引用条目 id；条目不存在/无素材时回退几何弹丸（射线类回退默认光束搭配），不影响战斗逻辑。

**条目结构**（`ProjectileArtDef`）：

| 字段 | 说明 |
|---|---|
| `id` / `name` | 条目 id / 显示名 |
| `kind` | 弹丸类别：`bullet` 实弹 / `shell` 炮弹（抛射）/ `missile` 导弹 / `ray` 射线；决定默认特效色与适配炮塔类型（直射→bullet、抛射→shell、导弹→missile、射线→ray；允许跨类借用，编辑器给出类别不匹配提示，按配置生效） |
| `projectileAsset` | 弹丸本体贴图：素材库「弹丸」分类条目 id；`'none'` = 显式无贴图（几何回退）；缺省 = 按条目 id 文件夹 `/res/projectiles/{id}/projectile.png` 回退，缺失即几何弹丸 |
| `trail` | 尾焰组（组在=生效）：行为模板 + 粒子参数 + 可选烟尾子组，见 §7.4 |
| `explosion` | 爆炸组（组在=生效）：火花+烟尘粒子爆发 + 多层冲击环 |
| `impact` | 命中组（组在=生效）：碎屑飞溅 + 中心亮点一闪 |
| `beam` | 光束表现组（仅 `ray` 条目有意义）：光晕/亮芯分层贴图 + 闪光 + 三组粒子，见 §7.5 |
| `spriteSet` | 遗留字段（编辑器不再提供）：素材文件夹名覆盖，兼容读取 |

特效（尾焰/爆炸/命中）一律由**程序化粒子参数**实时生成，无需序列帧素材；本体贴图为单张静态图。

**注册表约定**：

- `PROJECTILE_ARTS` 为**可变注册表**：编辑器就地修改条目字段/增删条目并 bump 即时生效，引擎与渲染零改动。
- **持久化**：每次编辑经 bump 将全量 JSON 写入 localStorage（`td-projectile-arts`，带版本信封）；应用启动时加载并就地替换注册表内容，解析失败/无存储环境静默使用出厂默认。「恢复出厂」清回出厂快照并删除存储键。
- **口令**：导出/导入口令携带弹丸库全量（`projectileArts`），导入以口令数据为准整体替换。
- 内置条目（`bullet_std` 标准实弹 / `shell_std` 标准榴弹 / `rocket_std` 标准火箭 / `ray_std` 标准射线弹）在编辑器内**不可删除**；新建条目 id 自动取 `custom_ammo_N` 递增，新建后自动选中。
- 出厂库共 6 条：上述 4 条内置 + 「集束导弹」（missile 类，惯性橙焰 + 长灰烟双尾迹）+「炮弹」（bullet 类，爆炸+命中）。

### 7.2 弹丸种类的美术与行为参数

四类弹丸共享"本体贴图 + 程序化特效"框架，差异在默认色与可用板块：

| 类别 | 适配炮塔 | 默认特效色 | 可编辑板块 |
|---|---|---|---|
| bullet 实弹 | 直射 | #F5E9C8 | 贴图 / 尾焰（含烟尾）/ 爆炸 / 命中 |
| shell 炮弹 | 抛射 | #F0A03C | 贴图 / 尾焰（含烟尾）/ 爆炸 / 命中 |
| missile 导弹 | 导弹 | #D9762E | 贴图 / 尾焰（含烟尾、大力喷射、喷口焰门控）/ 爆炸 / 命中 |
| ray 射线 | 射线（光束/点射） | #9AD9C8 | 光束表现 / 命中（hitscan 无弹道飞行，不提供尾焰与爆炸） |

**行为模板**（尾焰 `template`，覆盖顺序：模板默认 < 用户显式参数）：

- `standard` 标准拖尾（缺省）：rate 60、life 0.35s、size 0.06 格、惯性 0.2；
- `inertia` 惯性甩尾：惯性 0.9、life 0.5s——粒子随弹甩出弯曲尾迹；
- `pulse` 火焰脉冲：速率按 1.2Hz 振荡（0.4~1.6 倍）+ 尺寸/亮度闪烁；
- `smoke` 烟雾弥漫：rate 20、size ×2.5、grow 2 膨胀、暗灰色。

**特效生效门控**：组在=生效，未配置即无对应表现（引擎不添加任何默认特效）。爆炸特效仅在引用炮塔配置了爆炸（`blastRadius > 0`）时播放；直射实弹爆炸命中时爆炸与命中特效**同时**播放；抛射/导弹的爆炸命中只走爆炸特效；射线命中特效在光束每个 DoT tick 的端点触发。

### 7.3 弹丸编辑器 UI

调试面板「弹丸库」页签，左列表 + 右参数窗：

**左侧列表**

- 列表**最上方**为新建输入行（输入名称 + 新建，回车亦可）；
- 每条目显示类别色块、名称，名称下方子行显示类别名；贴图未就绪时子行附红色弱显提示（加载中「…」/「无素材」）；
- 单选切换，选中条目在右侧编辑。

**右侧参数窗**（自上而下）

1. **效果预览**：画布 360×108（深色底 + 弹道参考线，1px = 1px，弹丸贴图按原图尺寸绘制不缩放；窄容器等比缩小不超框）。单「播放/停止」按钮播放**全程动画**：
   - 非射线：弹体从左端飞入并按弹丸实际配置速度推进；实弹/抛射读取 `speed`，导弹逐帧读取初速度、延迟减速、加速度、极速与燃烧时间，并按 `M_PER_CELL` 换算为画布格速。弹体按解析参数喷尾焰/烟尾，到达右端命中点时按配置**同帧**触发命中碎屑与爆炸爆发，爆发结束停顿 0.9s 后自动循环；每轮均从初速度重新开始计算。
   - 射线：光束发射与实战一致——起射高速伸展（307.2m/s 从发射点扫出，粒子端点/命中闪光随前锋）→ 持续 5s → 停火消退 0.25s（长度冻结、光晕渐隐、亮芯收窄到 0%）→ 停顿 0.9s 循环重启；与战场共用引擎常量，两处永不脱节；
   - 门控：尾焰/命中/爆炸至少配置一项才可播（射线恒可播）；未播放时弹体居中静立。预览粒子层与战场同口径（烟尘贴图不加光、其余加法发光、贴图着色缓存），换贴图立即刷新。
2. **基础字段**：名称、类别（四类下拉）、弹丸贴图（素材库「弹丸」分类下拉：默认=按 id 文件夹 / 「无」= 强制几何弹丸 / 库条目）；附素材目录提示 `/res/projectiles/{id}/`。
3. **尾焰**（射线不显示）：整组增删（「+ 添加尾焰」/「删除该特效(回退)」）；模板为标准尾焰/惯性尾焰/脉冲尾焰/烟雾尾迹，另有颜色+渐变色取色器（一键回默认/无）、速率/寿命/尺寸/惯性/散开/尺寸变化/淡入数值框；**烟尾子组**在尾焰组底部：整组增删 + 寿命/持续/速率/颜色四字段。所有数值框留空 = 用模板/全局默认，占位提示显示当前生效值（所见即生效值）。

### 7.4 弹丸命中/爆炸/轨迹特效参数（概述）

- **尾焰 trail**：`template` 行为模板、`color`/`colorEnd`（寿命内变色，缺省仅亮度渐隐）、`rate`/`life`/`size`（粒/s、秒、格）、`inherit`（0~1 初速随弹比例，1 = 完全随弹）、`spread`（发射锥角弧度，缺省 0.6）、`grow`（>0 膨胀 <0 收缩）、`fadeIn`（淡入秒）；`smoke` 烟尾子组见 §6.4。烟团（grow>0）走烟雾贴图非加法渲染，其余粒子加法发光。
- **爆炸 explosion**：`template` 为 small/medium/large（默认 medium），模板按级别提高 `visualScale`、粒子数量、冲击环与闪光；`visualScale` 只改变视觉尺寸，不影响战斗判定。其余可覆盖参数包括 `color`、`duration`、`sparks`/`smoke`、`speedJitter`/`lifeJitter`、`turbulence`、`rings`/`ringSpeed`/`ringWidth`、`bias`、`inherit`、`fireball`、`shock`、`flash`、`streak`。
- **命中 impact**：`template` 为 bullet/armorPiercing/heavyArmorPiercing（默认 bullet），分别对应子弹、穿甲弹、大型穿甲弹；模板逐级增加粒子尺寸、数量、速度与持续时间。可覆盖 `color`、`duration`、`spikes`、`speed`、`life`、`size`、`drag`、`streak`、`angle`、`bias`。
- **射线光束表现**：见 §7.5 与第 8 章。

各参数的完整清单与默认值见第 2 章；渲染分层见第 11 章。

### 7.5 射线（ray）条目的光束表现

射线类条目以 `beam` 组承载光束分层表现（射线类炮塔经 `art.projectile` 引用本条目后生效）：

- **分层贴图**：光晕层 + 亮芯层贴图沿光束**原尺寸平铺**滚动（不缩放拉伸），加法发光、亮度闪烁（`flicker` 0~1，缺省 0.15；0 = 不闪烁）、`scrollSpeed` 贴图滚动（美术 px/s，按格宽缩放，缺省 96；0 = 静止）；缺省贴图 beam_glowA / beam_coreA（素材库「光束」分类），`'none'` = 该层回退程序化纯色矩形。
- **闪光**：炮口闪光（发射期间）与命中闪光（光束端点）贴图缺省 glow16.png，`'none'` = 不显示；`muzzleScale`/`impactScale` 尺寸倍率（缺省 1 = 100%）。
- **三组可选粒子**（组在=生效）：吸收粒子（发射点环带向心汇聚，缺省 12 粒/s · 亮芯色 · 0.05 格）/ 散发粒子（命中点飞溅，缺省 24 · 光晕色 · 0.05 格；`angle` 散发全锥角 0~360°，朝射线源方向为 0°，缺省 360 全向；粒子一律带电焊式拖尾亮线）/ 烟尘（命中点慢速上飘，不加光，缺省 6 · #3A3632 · 0.1 格）。
- 战场光束、弹丸库预览、炮塔预览三处同口径生效；命中粒子由 ray 条目 `impact` 参数在光束 DoT 端点驱动（未配置不产生事件）。
## 8. 射线炮（beam）

射线类炮塔 `type: 'beam'` 固定为持续光束，与实弹类的根本区别是**无实体弹丸飞行**，按持续 tick 完成命中和伤害结算。光束的分层贴图美术表现统一由弹丸库 ray 类条目的 `beam` 表现组提供（详见第 7 章 §7.5），炮塔经 `art.projectile` 引用 ray 条目即生效；本章描述炮塔侧的行为与参数语义。

### 8.1 光束攻击流程

射线炮塔固定走持续型武器状态机（与喷射同径）：起射 → 持续 `attackDuration` 秒（缺省 1）→ 停射进入冷却 `cooldown = max(reload ?? 0, fireRate)`；目标丢失、维持电量耗尽、资源标签门控或堡垒过热均立即停射。

- 发射期每个 DoT tick（`dot.interval` 秒）对宽幅矩形内全部敌人结算 `dot.damage`。
- 支持 `chargeTime` 充能前摇；`energyPerShot` 在起射时一次性扣除，`energyPerSec` 在持续期间逐帧消耗。
- 光束在首个阻挡弹道物体格截断，每个伤害 tick 同时对截断物体扣除 `dot.damage` 耐久。
- 出厂实例为磁轨光束塔：宽幅 1.28m、持续 3s、DoT 15/0.5s、充能 2s、发射电 15 + 维持电 5/s。

### 8.2 光束几何参数

- **宽幅 beamWidth（米）**：米→像素换算为 `beamWidth / 3.2 格 × cell px`（1 格 = 3.2m，基准格 32px，战场缩放时 `cell` 随缩放变化）。命中判定半宽 = `m2c(beamWidth ?? 0.256) / 2`（未配置时判定回退 0.256m），敌人体型尺寸计入判定宽度。渲染端未配置宽幅时按 1.024m 回退（仅几何回退口径）。
- **光束长度**：`beamMarch` 从炮塔中心沿炮口方向以 0.2 格步进推进，到达首个阻挡弹道物体格时截断（退回一个步长并记录截断物体），上限 `rangeMax`；命中判定为矩形覆盖（沿程 0~len、横向 ≤ 半宽 + 敌人体型）。
- **起射伸展**：光束起射时记录起射时刻 `beamOnAt`，光束以 `BEAM_ON_SPEED = 307.2 m/s` 从炮口高速伸展（32m 射程约 0.10s 到位），当前长度 = `min(截断全长, 已伸展距离)`；伸展期间 DoT 计时器不消费，伸展到位（或抵达阻挡物）当帧立即结算首次伤害；伸展前锋未触及的物体不扣耐久。停火时清除起射锚点。渲染（光束本体/光晕/亮芯/端点闪光）与伤害结算共用同一长度函数，视觉与伤害范围始终一致。
- **分层结构**：光束由**光晕层**（宽 = 宽幅，alpha 0.45 × 亮度系数）与**亮芯层**（宽 = **宽幅 × 0.5**，alpha 0.9 × 亮度系数）叠加而成，均加法发光（`'lighter'`）；染色缺省光晕 `#78C8DC`、亮芯 `#F0FAFF`，亮度按 `flicker` 幅度在 `[1−flicker, 1]` 内双频正弦闪烁（相位按炮塔 id 错开）。层素材缺省 `builtin:beam/beam_glowA` / `beam_coreA`，配置 `'none'` 或素材未就绪时该层回退为同颜色、同宽度的程序化纯色矩形。
- **端点与炮口**：炮口光球（缺省 glow16，尺寸 = 宽幅 × 2 × `muzzleScale` × 脉动）、命中点闪光（缺省 glow16，尺寸 = 宽幅 × 2.6 × `impactScale` × 高频脉动，位于光束端点）；另可配置吸收（发射点向心汇聚）/散发（端点飞溅）/烟尘（端点慢速上飘不加光）三组粒子，组配置在 = 生效。
- **起点定位**：光束/喷射的渲染起点对齐 barrel 0 的炮口点；未配置挂点表时同样读取自动生成炮口（单管默认前伸 0.35 格）。逻辑判定仍以炮塔中心起算。

### 8.3 充能帧条与起射前摇

- `chargeTime`（秒）为每次开火周期起射前的前摇（光束/喷射为每次持续发射前；实弹/点射为每轮前；轮内连发/齐射不重复充能）。充能期间不射击、不耗弹药/电量/产热；目标丢失或移出射程射界立即取消充能，重新索敌后重新充能。
- 充能素材为 `art.charge` 配置的**帧条**：按 `frames` 将素材横向等分（帧数钳制 1~12），从左到右顺序播放一遍、不循环；`offset` 为相对轴心的偏移（格，右 +x、上 +y）；`asset` 为素材库引用，`'none'` = 不播放，缺省回退素材文件夹 `charge.png`。
- **末帧语义**：前 N−1 帧占满 `chargeTime`，最后一帧恰在充能结束时点亮；点亮后再经 0.05s 末帧滞留（`CHARGE_LAST_HOLD`，不计入 `chargeTime`）才起射。持续型武器在攻击持续时间内（`firing` 且 `firingLeft > 0`）充能末帧**定格常显**，作为"正在发射"的持续指示。

### 8.4 停火消退 beamFades

光束停火（持续结束/目标丢失/资源中断/过热的统一 `firing` 下降沿）推入一条消退段：快照停火瞬间的起点、角度、当前光束长度与宽幅，存活 `BEAM_FADE = 0.25s`。消退段保持角度与长度不变，透明度按 `alpha = p^0.7`（p 1→0，前期更亮）渐隐，宽度随 p 收窄至 0；宽幅已配置时收窄量已并入层宽，亮芯层贴图另按 vScale = p 纵向收窄到 0% 且保持纵向居中。消退段沿用发射时的光束美术配置；点射不触发消退（其曳光 ttl 0.07s 自行消散）。

### 8.5 光束贴图平铺与缩放规则（drawBeamLayer）

光束贴图在局部坐标系（原点 = 光束起点，+x 沿光束方向）内绘制：

- **平铺不缩放**：贴图按原生尺寸沿轴向无缝平铺，块宽 = `img.width × texScale`、块高 = `img.height × texScale × vScale`，其中 `texScale = cell / 32` 适配战场缩放（32px = 基准格）；端部不足一块时按源矩形裁切。
- **滚动**：`scrollSpeed`（美术 px/s，缺省 96，0 = 静止）乘以 `cell/30` 换算后随时间累计，按块宽取模作为平铺相位偏移，形成沿光束方向的流动感。
- **宽幅驱动缩放（vScale）**：`beamWidth` 已配置时，贴图块高度经 vScale 缩放到目标层宽（光晕 = 宽幅换算像素、亮芯 = 宽幅 × 0.5 换算像素），与几何回退同宽；未配置宽幅时 vScale = 1，贴图保持原生高度。停火消退段复用 vScale 表达亮芯层收窄。
- **回退**：层贴图缺失（`'none'` / 加载失败）时该层绘制程序化纯色矩形，颜色/宽度与贴图层口径一致；块高收窄到 0.5px 以下跳过绘制。
- **瞬时命中曳光**：供单位 hitscan 等非炮塔瞬时命中表现复用同一套分层平铺绘制（光晕 + 亮芯 + 端点命中闪光），宽度固定 `cell × 0.4`，ttl 0.07s 内随存活比例渐隐；素材全部不可用时回退双描边细亮线（外层青色 2.5px + 内芯白色 1px）。

## 9. 近战与生产炮塔（melee / produce）

### 9.1 近战炮塔：现行设计中不存在

炮塔武器类型枚举 `WeaponType = 'direct' | 'lob' | 'missile' | 'beam' | 'spray'` 不含近战类型，`TurretDef` 无近战相关字段，`TURRET_DEFS` 出厂配置中也没有任何近战炮塔；引擎与渲染层均无近战攻击分支。因此炮塔编辑器不提供"近战"类型选项——本章保留仅为明确该口径。如未来加入近战炮塔，需同时扩展类型枚举、伤害结算与编辑器面板。

### 9.2 生产类：内部模块而非炮塔

生产行为不挂在炮塔体系，而是移动堡垒**内部模块**的属性：`ModuleDef.produce?: { kind: AllyKind; interval: number; cap: number }`（周期产出友军单位，`cap` = 本模块产出单位同时存活上限）。出厂生产模块：

| 模块 | 产出 | 间隔 | 存活上限 |
|---|---|---|---|
| 机器人模块 | 无人飞行器 | 8s | 6 |
| 坦克制造模块 | 统一载具 | 15s | 3 |
| 无人机模块 | 无人飞行器 | 20s | 2 |

结算规则（引擎每帧推进，备战/交战阶段均生效）：

1. 模块放置时计时器初始化为 `interval`（放置即开始倒计时）；
2. 倒计时到点后先统计本模块产出且仍存活的友军数（按 `producerId` 归属），达到 `cap` 则计时器重置为 0.5s 稍后复查，不产出；
3. 未满员则重置计时器为 `interval / 生产特殊格倍率`（模块覆盖堡垒内部「生产」特殊格时倍率为 1.5，即间隔 ÷1.5），并在堡垒前沿出生点生成 `unitDefId` 指向的统一单位。

产出的友军单位按自身组合式 AI 行动，可被敌人击毁，不占炮位、不耗堡垒资源；其生命、移动、攻击、弹丸与美术全部读取统一单位定义。

## 10. 命中效果与伤害表现

### 10.1 爆炸伤害（blast 参数组）

炮塔侧爆炸由两个字段表达：

- `blastRadius?: number`——爆炸半径（米），未配置或 ≤0 = 该武器不爆炸；
- `blastEffect?: BlastEffect`——`{ damage: number; burn?: { damage; interval; duration } }`：爆炸附加伤害与命中燃烧（燃烧为持续伤害：每 `interval` 秒结算 `damage`，持续 `duration` 秒，挂载到目标 dot 队列）。

爆炸结算（`explode`）规则：

- **范围判定**：敌人中心距爆心 ≤ 半径（米转格）+ 敌人体型尺寸即被波及；**伤害无距离衰减**，范围内一律全额 `(爆炸基底伤害 + blastEffect.damage) × 等级系数`，随后附加燃烧 dot；
- **遮挡豁免**：爆心→目标之间存在阻挡弹道的物体（格级视线按 0.2 格步进采样，爆心近场 0.5 格内不计以避免"自我遮挡"）时，该目标豁免本次爆炸；
- **物体波及**：矩形物体按中心 + 半尺寸判定，命中即足额摧毁伤害（`hp = -1` 的不可破坏物体豁免）；油桶被波及摧毁时产生燃烧区域与爆炸圈；爆炸不伤己方墙段；
- **结算顺序**：先登记爆炸视觉事件，再逐敌人结算（遮挡判定 → 伤害 → 燃烧挂载），最后逐物体波及结算。

爆炸触发点按武器类型区分：

| 武器 | 触发点 | 半径 | 伤害基底 |
|---|---|---|---|
| 抛射（lob） | 落点 | `blastRadius ?? 15` | 弹丸伤害（直击并入爆炸一次性结算） |
| 导弹（missile） | 命中点/锁定落点 | `blastRadius ?? 20` | 弹丸伤害 |
| 直射（direct） | 命中敌人处 / 命中阻挡物体处（仅 `blastRadius > 0` 时） | `blastRadius` | 0（直击伤害已按穿透衰减另行结算，波及目标只吃爆炸） |
| 炮塔毁坏 | `onDestroyBlast`（`BlastEffect & { radius }`）在炮塔位置触发 | 配置值 | 配置值 |

### 10.2 命中事件与冲击视觉反馈

- **impacts 命中事件**：实弹命中（爆炸命中时与爆炸事件同时推入）、光束 DoT 端点（每个伤害 tick）均推入命中事件（ttl 0.15s，携带弹丸条目 id）。实弹命中点取敌人身体视觉中心（脚底锚点上方体型 × 精灵高系数）再加每次不同的确定性抖动（半径 ≤ 体型 × 0.6），保证次次位置有差异。
- **命中特效解析**：由弹丸库条目的 `impact` 参数驱动（`color`/`duration`/`spikes`）——首见时喷射 `spikes` 个短寿命碎屑飞溅粒子（缺省 5 个、颜色缺省弹丸类别色），随后中心亮点一闪（矢量渐隐，`duration` 缺省 0.15s）。条目未配置 `impact` → 不产生事件、不播放任何命中特效。
- **受击闪光**：敌人每次受伤获得 0.08s 受击闪白（`hitFlash`），是所有伤害（含爆炸、DoT、光束 tick）统一的即时反馈。
- **爆炸视觉**：配置了爆炸（`blastRadius > 0`）且引用弹丸条目含 `explosion` 参数组时，播放粒子爆炸——v2.54 统一画法：径向渐变火球 + 软边冲击环（`shock=0` 回退细描边环）+ 瞬时照明光晕 + 拉丝火花/烟尘两组粒子（初速、尺寸按爆炸半径缩放，支持方向偏置与命中弹速继承）；其余情况回退程序化爆炸圈（橙黄填充 + 描边，0.35s 扩散渐隐）。堡垒毁灭演出爆炸（`ExplosionFx.kind`）v2.54 起复用同一画法（固定橙金配色，不读弹丸库）。
  - **v2.55 画法共用层 `fxDraw.ts`**：粒子池绘制（`drawParticlePool`）、爆炸矢量层（`drawExplosionLayers`）、命中闪光（`drawImpactFlash`）及染色缓存/hex 工具统一迁至 `src/game/fxDraw.ts`，战场渲染（render.ts）与编辑器弹丸预览（AmmoPreview）均调用同一组函数——设定依据：v2.54 爆炸升级曾漏同步预览（平行实现漂移），画法收敛到单点后此类事故结构性消除；驱动层仍各自保留（战场 = 游戏事件 + fxSeen 首见 spawn；预览 = fxTick 状态机），仅画法共用。炮塔美术预览（drawArtPreview/drawPreviewRack）因坐标系为像素空间且涉及炮位布局叠加层，统一工作见待开发记录 #15。

### 10.3 击杀飘字与伤害数字

现行设计**不做逐次伤害数字跳字**；飘字仅用于事件性提示，统一由 `floats` 队列承载（ttl 0.8s，金色 `#D9A441` 粗体描边字，随存活时间上移约 16px 并渐隐）：

- **击杀赏金**：敌人 hp ≤ 0 进入击杀结算——资源 `+bounty`、击杀数 +1，并在敌人位置飘字「+N」；
- **其他事件飘字**：「炮塔损毁」「建筑被毁」「××（友军）阵亡」。

### 10.4 表现分层

命中与伤害表现在战场渲染顺序中位于：炮口火光 → 射线/喷射（含光束分层贴图与端点闪光）→ 光束停火消退段 → 爆炸（粒子/程序化圈）→ 命中特效（碎屑 + 亮点）→ 粒子层（尾焰/烟尘/吸收散发等）→ 曳光与脉冲射线 → 飘字。各层的绘制次序、画布合成方式（加法发光/普通）与战场缩放适配的完整规范见第 11 章「渲染分层」。
## 11. 美术与渲染分层

本章描述炮塔/弹丸的贴图分层模型、堡垒特效点粒子系统、整帧渲染分层顺序，以及素材库（assetlib）的组织与分发约定。实现位于 `src/game/art.ts`、`src/game/fortressFx.ts`、`src/game/particles.ts`、`src/game/render.ts`、`src/game/assetlib.ts`，配置类型位于 `src/game/config.ts`（`TurretArt` / `FortressEffectPoint` / `ProjectileArtDef`）。

### 11.1 炮塔贴图结构（分层合成）

炮塔视觉按**层**合成，每层独立解析素材、独立降级。层清单（`TurretArtAssets`）：

| 层 | 字段 | 行为 |
| --- | --- | --- |
| 底座 base | `art.baseAsset` | 居中于占格；挂载炮塔随船体朝向旋转，地面炮塔不旋转；默认无，不绘制 |
| 炮身 turret | `art.turretAsset` | 以 `art.anchor`（占格归一化坐标，缺省 `[0.5,0.5]`）为旋转轴心，随瞄准方向旋转；默认无，不绘制 |
| 炮管 barrel × N | `art.barrelAsset` | 每管一根，根部锚定挂点 `mount`；默认无，不绘制，挂点/炮口/火光逻辑不受影响 |
| 开火效果 flash | `art.flashAsset` | 默认无，不播放。显式选素材后按横向帧条 2 帧 × 每帧 0.1s、逐帧缩放 1.4×→1×、加法发光（`lighter`）播放；宽 < 高×帧数的单张图整图绘制、逐帧脉冲缩放 |
| 辉光 glow | 文件夹 `glow.png` | 可选；默认仅过热时显示（`art.glow.overheatOnly`，缺省 true） |
| 充能 charge | `art.charge.{asset,offset,frames}` | 可选帧条：按帧数横向等分（1–12 帧）、从左到右顺序播一遍，帧时长 = 充能时间/帧数；充能结束末帧短暂滞留后在攻击持续期内定格常显。`'none'` = 不播放，缺省走文件夹 `charge.png` |

**分层就绪规则**：`turretArtState()` 对显式选择且正在加载的四个可见层返回 `loading`，加载完成或没有需要加载的层时返回 `ready`。`ready` 资产集中只包含成功加载的层；缺失、失效和未选择的层保持透明，不再进入 `fallback` 几何绘制。

**每层素材源解析**（`turretLayerSrcs()`，纯函数）：

1. `art.baseAsset/turretAsset/barrelAsset/flashAsset` 为有效素材库条目 id 时，经 `assetImage()` 取条目 src；
2. 字段缺省、`'none'`、遗留 `'geo'` 或引用不存在时返回空层；不再读取 `spriteSet/id` 文件夹约定，也不再提供几何回退；
3. 旧存档升级到炮塔定义 schema v14 时，四层缺省值与 `'geo'` 会统一迁移为 `'none'`，显式素材引用保持不变。

**挂点表 `art.barrels`**：每项 `{ mount, muzzle }`，坐标相对轴心、单位格，基准系为「炮口朝上」：x 向右为正、y 沿炮口方向为正。`mount` 是炮管根部锚点，`muzzle` 是弹丸出生点与火光定位点。挂点表数量应与逻辑炮管数（`def.barrels`，缺省 1）一致；不一致时**渲染/出生点以挂点表为准**，`validateArt()` 给黄色警告。未配置挂点表时引擎按逻辑炮管数自动生成：单管挂点为 `[0,0]`、炮口为 `[0,0.35]`；多管沿垂直炮口方向均布（展开宽度 = 占格宽 × 0.6），炮口同样前伸 0.35 格。后坐为统一参数 `art.recoil`（全管共用，缺省 0.1 格，0 = 无后坐动画），击发后炮管在 2× 火光时长内线性回位。

**多管与双管示例**：发射模式 `barrelMode` 分齐射（salvo，全管同时）与轮流（sequential，按 `burstInterval` 轮转各管，`barrelIdx` 推进）。出厂哨戒机枪（`mg`）即双管轮流：炮身贴图引用内置素材 `DualGun-_S1`、炮管贴图引用 `DualGun-_S2`，`barrels: 2 / barrelMode: 'sequential'`，挂点表给出左右两个挂点（(-0.1, 0.25) / (0.1, 0.25)）与对应炮口，`zBias: -1` 使炮管层压在炮身层之下（根部被炮身遮盖）。`zBias < 0` = 炮管在炮身之下，`>= 0`（缺省）= 炮管在上。

**导弹挂载显示**：导弹塔（`type: 'missile'`）默认在炮管旁显示待发弹架（`art.rack.show`，缺省 true；`rack.dx/dy` 为挂载点相对炮管挂点的偏移，缺省 0 / 0.12 格）。待发弹逐发消耗、打空显示空架、装填完成逐枚复挂（复挂弹带 0.25s 推入渐显动画，仅作用于最新一枚）；轮流模式下从当前管侧优先消耗。弹体用所引用弹丸条目的本体贴图，无贴图回退类别色几何小导弹。

**尺寸与层级（zLevel）**：所有贴图按原始像素尺寸绘制，基准格统一 `BASE_CELL = 32px`——缩放 1 时 1 贴图像素 = 1 画布像素，横竖屏/任何设备贴图与网格比例恒定，随用户缩放等比变化；像素风一律最近邻采样（关闭平滑）。战场上多座炮塔重叠时的叠放次序由渲染层级键决定（`turretRenderKey()`，升序绘制、靠后叠在上，稳定排序保持同键放置先后）：

1. 第一层级 = 车体分层：`zLevel <= -1` 的挂载炮塔在载具主体之前绘制并被主体素材覆盖，`zLevel >= 0` 的挂载炮塔在主体之后绘制；地面炮塔不参与车体遮挡；
2. 同一车体分层内的第一排序键 = 槽位尺寸 rank：**尺寸越小越底层**（S=0 < M=1 < L=2）；
3. 同一尺寸的第二排序键 = 挂载炮位的 `zLevel`（缺省 1，越大越上层）；地面炮塔视为 1。

**校验**：`validateArt(def)` 输出 `errors`（硬性错误，编辑面板红标）与 `warnings`（提示，黄标）。硬错误包括 anchor/挂点/炮口非数值对、后坐为负、充能帧数越界（1–12）、光束组颜色非 `#RRGGBB`、缩放非正数、粒子组速率/尺寸非法等；警告包括挂点数≠炮管数、喷射塔配弹丸引用（不生效）、弹丸类别与炮塔类型不匹配（允许跨类借用，按配置生效）、引用不存在的素材条目（回退程序化/几何表现）、配了充能动画但未配充能时间等。

### 11.2 光束与弹丸表现（美术侧口径）

**光束分层**（远行星号式，配置挂在弹丸库 `ray` 条目的 `beam` 组上，炮塔经 `art.projectile` 引用解析，`beamArtConfigOf()` 为无炮塔上下文的复用入口）：

- 光晕层（glow）+ 亮芯层（core）：贴图沿光束轴向平铺滚动（`scrollSpeed`，美术 px/s，缺省 96）、加法发光、亮度闪烁（`flicker` 0~1，缺省 0.15）；染色 `fringeColor`（缺省 `#78C8DC`）/ `coreColor`（缺省 `#F0FAFF`）；白图 alpha 遮罩经 `tintedFx` 预着色缓存复用。层素材 `'none'`/未就绪 → 该层回退程序化矩形。
- 炮口光球（muzzle）与命中点闪光（impact）：缺省 `glow16`，尺寸分别 ×`muzzleScale`/`impactScale`（缺省 1），高频脉动、加法发光。
- 宽幅联动：炮塔配了 `beamWidth`（米）时贴图高度缩放到 宽幅/3.2 格（光晕=宽幅、亮芯=宽幅×0.5）；未配 = 贴图原生高度。
- 三组粒子（组在 = 生效，颜色缺省随本组配色）：吸收 absorb（发射点环带向心汇聚）、散发 scatter（命中端点飞溅，加法发光 + 电焊式拖尾亮线；`angle` 为朝射线源方向 0° 的全锥角，0–360°，缺省 360 全向）、烟尘 smoke（命中端点，膨胀不加光）。
- 停火消退：保持停火角度/长度，宽度收窄 + 渐隐（alpha = p^0.7，亮芯收窄到 0%）。

**弹丸条目美术**（`ProjectileArtDef`，详见弹丸库章节）：本体 `projectileAsset` 解析链与炮塔分层同构（素材库引用 → `/res/projectiles/{folder}/projectile.png` 文件夹；`'none'` = 显式几何弹丸），本体贴图为 ready 必需件，trail/explosion/impact 文件夹帧条为可选回退件。尾焰/爆炸/命中一律以**程序化参数段**为准（`resolveTrailFx/resolveExplosionFx/resolveImpactFx`，段在 = 生效）：尾焰四模板（standard 标准 / inertia 惯性甩尾 / pulse 火焰脉冲 / smoke 烟雾弥漫，参数覆盖顺序 = 模板默认 < 显式参数），可叠加长存留烟尾子组（`trail.smoke`，可选「持续」窗口，战场侧按引用炮塔燃烧时间钳制）；爆炸段含火花/烟尘双组粒子 + v2.54 统一矢量层（径向渐变火球 + 软边/描边冲击环 + 瞬时照明，火花可拉丝）；命中段为碎屑飞溅 + 中心亮点一闪。未配置特效段 = 无任何默认效果（无尾焰配置即无尾迹、无喷口焰）。

### 11.3 特效点系统

堡垒特效点（`FortressDef.effects: FortressEffectPoint[]`）是**贴附船体的程序化粒子发射点**，仅视觉、不参与碰撞，按堡垒停止/移动状态切换播放。发射位置随船体位姿（位置 + heading 旋转，与渲染堡垒上下文同一变换）；**粒子离口即在世界空间独立运动**，已散发的烟/尘不再跟船。

配置字段：

| 字段 | 含义 |
| --- | --- |
| `id` / `x` / `y` | 标识与堡垒局部坐标（格，可为小数） |
| `kind` | 粒子种类：smoke 烟雾 / flame 火焰 / dust 尘土 / spark 火花 |
| `state` | 播放门控：idle 停止时 / move 移动时 / both 始终 |
| `layer` | 渲染层级：ground 地面层 / air 空中层（缺省：dust=ground，其余=air） |
| `rate` | 发射速率（粒/s，缺省按 kind） |
| `size` | 粒子尺寸（格，缺省按 kind） |
| `life` | 粒子寿命（秒，缺省按 kind） |
| `inherit` | 堡垒速度继承 0~1（缺省：dust=0.3 被车带起前扬，其余=0 不随车） |

各 kind 缺省口径（`KIND_DEFAULTS`）：smoke（air，8 粒/s，0.12 格，1.3s）、flame（air，24，0.08，0.28s）、dust（ground，14，0.14，0.9s，inherit 0.3）、spark（air，7，0.05，0.22s）。运动形态按 kind 程序化（不开放方向参数）：烟雾 = 上升扩散烟团（膨胀至半寿命后冻结尺寸渐隐）；火焰 = 短寿命加法火焰（金→橙渐变 + 高频闪烁）；尘土 = 横向弥散 + 按 inherit 继承车速；火花 = 随机方向短促亮线（电焊拖尾）。发射按 rate 累加器跨帧连续累计（避免小数粒截断闪烁），各点以坐标 hash 错开首粒相位。

**粒子池双通道**：渲染端持两个粒子池——`groundPool`（地面层：尘土等，绘制于地形之上、载具及行走部件之下）与 `fxPool`（空中层：烟雾/火焰/火花、弹丸尾焰、爆炸、光束粒子等，绘制于弹丸与爆炸之后的最上层附近）。发射按 `layer` 路由入池。粒子系统为渲染端纯视觉、纯函数可 sim：每池固定上限 `PARTICLE_CAP = 400`，超出回收最老粒子；逐帧运动（位置积分 + drag 减速 + 膨胀/收缩 + 湍流 + 寿命衰减）由 rAF wall-clock dt 驱动（clamp 0.1s 防后台切回大步长），编辑模式不发射特效点粒子。绘制口径：`grow > 0` 的膨胀粒子（烟尘类）走 smoke32 贴图、正常混合不加光；其余走 particlealpha32 贴图 + 预着色 + 加法发光；颜色渐变按寿命进度 color→colorEnd 量化 8 档缓存。

### 11.5 素材库（assetlib）

素材库（`src/game/assetlib.ts`）是统一的图片条目注册表，供炮塔分层、弹丸本体、光束、模块、履带/轮子等各处按 id 选配引用。条目结构 `{ id, name, src, builtin, category }`，src 为 dataURL（上传）或 `/res/` 文件路径（内置）。

**分类**（`AssetCategory`）：base 底座 / turret 炮身 / barrel 炮管 / flash 效果（开火火光、命中/炮口闪光等特效贴图）/ projectile 弹丸 / charge 充能 / beam 光束 / module 模块 / other 未分类。选配下拉**严格按分类过滤**（选底座时不显示底座以外素材；未分类条目不出现在任何选配下拉，可在素材库页签改分类）；当前引用与分类不符时仅给黄色提示，不作硬拦截。

**/res/ 目录结构**（`public/res/`，按分类组织）：`beam/`（光束贴图）、`fortresses/`（遗留载具贴图路径）、`vehicles/`（载具/行走部件）、`fx/`（粒子特效）、`ground/`（三层地面）、`library/`（内置常用素材）、`projectiles/`（弹丸）、`turrets/`（炮塔分层文件夹）、`walls/`（城墙图集）。代码内出现的 `/sprites/` 前缀引用会被 `resCompatUrl()` 自动重写为 `/res/`，存量口令/存档中的引用不失效。

**两类条目**：

- **内置条目**（`builtin: true`）：代码注册、随应用分发，**不可删、不持久化、不随口令导出**。当前内置 = 常用素材组（`builtin:library/{文件}`：炮身/炮管/弹丸/充能/开火效果/履带瓦片等，展示名可与文件名不同）+ 光束组（`builtin:beam/*`，/res/beam/）+ 特效组（`builtin:fx/*`，/res/fx/）。素材文件夹约定解析（`art.spriteSet`、条目 id 文件夹）的注册机制保留，通用兜底集已废止——无素材即几何绘制。
- **上传条目**（`upload-N`）：本地图片转 dataURL（PNG/JPG，单张超 500KB 给软警告仍允许），`localStorage 'td-asset-lib'` 持久化；可删、可改分类、随口令导出。出厂上传素材以 dataURL 内联在代码中，**仅首次启动播种**（无存储 key 时写入并落盘，此后删除不复活）。无存储环境（sim/node）转为内存播种。

**口令烘焙（概念）**：编辑器中经口令搬运验证成熟的配置，可以两种形式沉淀为随应用分发的出厂内容——① 素材：图片文件落位 `/res/` 对应目录并注册为内置条目（或内联为出厂上传播种），原口令中的上传引用随之转为内置引用；② 定义：炮塔/弹丸参数直接写入 `config.ts` 的 `TURRET_DEFS` / `PROJECTILE_ARTS` 出厂表。烘焙后口令侧无需再携带对应内容；素材贴图文件级替换（只换文件、不动注册/分类/引用）是同口径的后续维护方式。

**导入导出**：口令仅携带上传条目（`uploadsForExport()`）；导入按 id 去重合入并持久化（`importUploads()`），口令无 assets 段时不动现有库。素材图片按条目 id 缓存加载，无 DOM 环境静默 error。

## 12. 炮塔编辑器 UI

炮塔编辑器是 DEBUG 面板（`src/components/DebugPanel.tsx`）的「炮塔」页签；同一面板内还有弹丸库、素材库、地形/物体、战场编辑器、堡垒、模块页签，顶栏常驻导出/导入/重置/关闭。所有编辑都经统一的 `bump()` 通道：刷新界面 + 即时持久化（见 §13.2），修改对新旧炮塔均即时生效。

### 12.1 页签布局

- **新建自定义炮塔**：选武器类型（直射/抛射/导弹/射线/喷射）+ 可留空名称，按该类型原型克隆出 `custom-*` 条目，创建后自动选中，并即刻出现在备战卡片栏可放置试玩。
- **左列表右参数窗**：左侧为炮塔定义单选列表（色块 + 名称 + id，自定义条目带标记）；右侧为当前条目的完整表单。自定义条目可改名、可删除（删除时同步移除场上已放置的同型炮塔）；内置条目不提供删除。
- 参数区与美术配置区横版并排（竖版上下堆叠），两个板块均常驻显示、无折叠。

### 12.2 参数面板（字段显隐规则）

参数表由声明式字段规格数组 `FIELDS` 驱动：每项 `{ path, label, tip, type, step, options, showIf, get, set }`——`path` 支持 `a.b` 嵌套；`tip` 为悬停/长按解释气泡；`type` 分 number / boolean / select；`get/set` 用于派生/复合字段（如「制导模式」下拉读写 `guided` + 清理/保留延迟制导字段、「集束子弹数」读写在填入时自动补默认扇角/近炸距离），提供后读写绕过通用 path 存取。

**显隐规则**：

- 字段带 `showIf(def)` 的，按谓词显隐（多为类型相关：导弹系的制导/集束/燃烧时间字段仅 `type: 'missile'` 显示，充能时间仅射线类显示，发射模式仅直射/抛射/导弹显示等）；`showIf` 不依赖字段自身值，避免编辑中间态（空/0）导致字段自隐藏。
- 不带 `showIf` 的为**可选参数**：字段在定义上有值才显示（删空即隐藏，回归未配置语义）。
- 常驻字段（`showIf: () => true`）：爆炸半径/爆炸附加伤害/燃烧三参、炮管数——保证未预置爆炸的炮塔也能直接填入开通爆炸。
- 数值输入统一最小调整值 0.1（个别字段声明更大步进）；带 `showIf` 的字段可清空（清空 = 未配置），常驻可选字段删空停留于本地编辑、失焦回落。

**尺寸规则**：编辑器保留 S/M/L 尺寸选择，炮塔只能挂到相同尺寸的炮位；尺寸不再联动 w/h，也不再生成 1×1、1×2、2×2 占格。w/h 仅保留为旧美术坐标范围。

### 12.3 标签编辑器（索敌标签）

`TagEditor` 常驻于参数表下方，编辑 `def.tags`：已配标签以 chips 形式横排展示（文案如「偏好·血最多优先」「偏好·导弹优先」「约束·不攻击导弹」「资源·弹药低于20%禁火」），每个 chip 带 × 移除，删空即删除 `tags` 字段；有「清空」按钮一键恢复默认索敌。新增区为三段联动：类别下拉（偏好/约束/资源）→ 对应键下拉（偏好九键，含导弹优先；约束三键，含不攻击导弹；资源四键：弹药/电量/热量/防御）→ 资源类再选「低于/高于」与百分比阈值（钳 0–100）。同键（资源类同键同向）重复添加被去重拦截。语义细节见索敌系统章节。

### 12.4 美术配置块与预览

**美术配置块**（`ArtEditor`）：未配置时显示「+ 启用美术配置」（启用即填入默认骨架：轴心居中，底座/炮身/炮管/火光均为无，统一后坐 0.1，单挂点表）；已配置时标题栏显示校验徽标（红 ✕=errors 数 / 黄 ⚠=warnings 数，`validateArt()` 口径）。所有修改在结构化克隆上进行、整体写回。表单内容：

- 分层素材下拉 ×3（底座/炮身/炮管）：首项统一为「无（不绘制）」且为默认值，其后为素材库按分类过滤的分组（内置/上传）；不再提供「默认（文件夹/几何绘制）」或「几何」选项。当逻辑炮管数 ≥2 时，炮管项右侧显示「翻转」勾选框，默认关闭；开启后只对第2、4、6……根偶数炮管的贴图做水平镜像，不改变挂点、炮口、弹丸出生点、开火顺序或战斗参数。
- 弹丸引用下拉（喷射塔不显示）：直射/抛射/导弹标签为「弹丸」，射线类标签为「光束(弹丸)」——引用 ray 条目即接管光束分层表现与命中特效；选项按弹丸四类分组。
- 火光下拉：默认「无（不播放）」，不再提供文件夹/几何默认项；表现参数硬编码不提供编辑。
- zBias（<0 炮管压炮身之下）与统一后坐（写入时清理逐管遗留后坐值，避免双源）。
- 轴心 x/y：界面以炮塔原点为 0px 显示炮身贴图轴心偏移；存档继续使用归一化坐标以兼容旧数据。
- 炮管挂点卡片：数量由「炮管数」决定、不提供手动增删；每卡编辑挂点 x/y 与炮口 x/y；未配置的管显示「默认」并按引擎均布规则预填。
- 导弹塔附加「挂载显示」开关与挂载 x/y 偏移；射线类附加「充能动画」子组（充能 x/y、帧数 1–12、素材下拉）。

**炮塔预览**（`ArtPreview` / `drawArtPreview`）：深色底方形画布只绘制 32×32px 完整方格，不显示半格细分线或 X/Y 坐标轴。炮塔原点固定在画布中心并以红色十字标记，修改轴心坐标时仅改变炮身/辉光贴图相对原点的位置；炮位、挂点、炮口和战斗原点保持不动。预览与战场渲染严格共用「32px = 1 格」美术坐标基准——缩放 1 时预览与战场逐像素一致。绘制内容与战场同规则：只绘制显式选择且加载成功的分层贴图、zBias 次序、挂载弹架满挂展示、充能帧条第 1 帧；空层保持透明。「标注」勾选框统一显隐轴心（红色十字）、挂点（蓝，挂1/挂2…）、炮口（红，口1/口2…）、后坐虚线箭头；只有配置火光素材时才显示火光尺寸参考圆。「播放动画」按钮循环播放射击流程：充能前摇（含末帧滞留）→ 击发（火光 2 帧 + 炮管后座回位）→ 按连发数/连发间隔轮转各管，周期不低于开火间隔；光束/喷射为充能后持续开火（光束矩形/喷射扇形 + 火光循环 + 光束三组粒子），击发弹丸从炮口飞出。素材加载中/完成后预览自动升级，无需手动刷新。

核心炮塔画法不再由预览复制实现：`drawTurretPreviewCore()` 调用战场同一套 `drawTurretLayers()`，统一底座/炮身/炮管的显式素材渲染、空层透明、后座、充能和导弹挂架；预览侧只负责网格、轴心/挂点/炮口标注以及动画流程驱动。

参数区上方的「热管理预览」调用 `simulateTurretHeat()`，按当前出战堡垒的热量上限与散热能力模拟连续射击 20 秒，显示热量曲线、峰值与首次过热时间；模拟为只读，不改动对局。

**光束预览**：光束表现（分层贴图/闪光/三组粒子）在弹丸库 ray 条目上编辑，其预览见 §12.6 的弹丸预览——ray 条目的播放动画即光束预览：起射按速度伸展（端点闪光随前锋）→ 持续 5s → 消退消失（长度冻结、光晕渐隐、亮芯收窄到 0%），停顿后循环，与实战口径一致。

### 12.5 安装/卸载与炮位约束（概述）

炮位的定义与编辑（位置/尺寸/类型限制/视角/层级/隐藏炮塔素材）属单位域（见堡垒编辑器设计），炮塔侧只消费其约束：

- **安装**：备战阶段按下「炮塔」按钮展开卡片栏（牌面显示名称、尺寸、造价；负担不起的置灰），点选卡片进入挂炮模式——战场上显示全部炮位的槽位圈与视界弧，尺寸和类型兼容的空闲炮位高亮，点击即挂载（`canMountTurret()` 校验：炮位存在、尺寸匹配、类型兼容、未被占用、费用充足）。挂载初始朝向按炮位视角：全视角 = 船头向 / 指定视角 = 视界中心 / 固定视角 = 固定角。
- **卸载**：拆除工具点中炮塔即卸下并返还半价（仅备战期）；炮位是否隐藏炮塔素材不影响卸载。
- **视角三模式**在编辑器中的体现：堡垒编辑器炮位条目提供「全视角 / 指定视角 / 固定视角」下拉（指定视角编辑起止角，支持跨 0°；固定视角角度钳 -180~180°，上方 0° 顺正逆负），预览同步显示视界扇形/单射线；战场上选中炮塔时按其炮位视角绘制射界指示——固定视角画单射线、指定视角画相对船头的视界扇形、全视角画整圆，并叠加最小射程盲区与免转瞄准锥（射角）。炮塔定义本身不再有射界字段，地面炮塔 360° 自由旋转。
- **渲染层级**：炮位 `zLevel`（缺省 1）决定炮塔重叠时的叠放次序（§11.1）。

### 12.6 弹丸编辑器入口

弹丸编辑并入同一 DEBUG 面板的「弹丸库」页签（`AmmoTab`），操作模式与炮塔页签一致：左列表右参数窗、新建条目（`custom_ammo_N`，缺省几何弹丸）、选中即编辑、修改经 `bump()` 即时生效持久化。右参数窗顶部将名称、类别、子类、贴图纵向排列在预览图左侧，不再显示素材目录提示；删除按钮常显，自定义弹丸可删除，内置弹丸禁用删除。战斗参数、垂发、音效、尾焰、烟尾、爆炸、命中均采用统一的双列/宽屏四列参数网格、字段宽度和分组标题。条目字段：名称、类别（bullet 直射弹 / shell 抛射弹 / missile 导弹 / ray 射线）、本体贴图选配（素材库弹丸分类 / 「无」= 几何弹丸）、尾焰/爆炸/命中三个程序化特效段；导弹条目另有“可拦截”和“拦截耐久”；ray 条目附加光束表现组（光晕/亮芯/命中闪光/炮口光球素材与颜色、闪烁、滚动速度、双向闪光缩放、吸收/散发/烟尘三组粒子）。**弹丸预览**（`AmmoPreview`）：360×108 深色画布，弹体按原图尺寸静立或随动画飞行；单「播放/停止」按钮播放从左飞行到右端命中/爆炸的全过程循环（ray 条目为光束起射→持续→消退循环）；未配置任何效果的条目不可播（射线恒可播）。炮塔侧的弹丸入口即美术配置块的「弹丸 / 光束（弹丸）」下拉（§12.4）。

## 13. 口令、持久化与模拟回归约定

### 13.1 配置口令（导入/导出）

口令是全部 debug 配置的跨设备搬运格式（`src/game/config_transfer.ts`）：`exportConfig()` 实时取注册表现状打包为 bundle，序列化后 base64 编码（纯 JS 实现，UTF-8 字节 ⇄ base64，unicode 安全，容忍粘贴带入的空白/换行）。bundle 形状：

```ts
{
  app: 'td-config',
  version: 4,
  turretDefs,        // 炮塔定义全量
  projectileArts,    // 弹丸库全量
  level,             // 战场关卡
  assets,            // 素材库上传条目
  fortressLib,       // 堡垒类型库（自定义堡垒 + 出战选择）
  moduleDefs,        // 模块库
}
```

**版本兼容语义**：`version` 接受 1/2/3/4；各段按引入门槛可选——version ≥2 携带 assets、≥3 携带 fortressLib、≥4 携带 moduleDefs；低版本口令缺失的段**不动导入方现有数据**（按 id 去重合入或保持原状），携带的段以口令数据为准。旧炮塔的 `mount` 与 w/h 字段原样兼容读取；槽位尺寸继续参与匹配，w/h 不再按槽位尺寸归一化为占格。

**导入保证**：解析与形状校验（base64 → JSON → `app` 标识/版本/各段形状）全部通过后，才一次性就地替换注册表并落盘；任何一步失败不写坏现有数据。`parseConfigSmart()/applyConfigSmart()` 支持双格式：以 `{` 开头的文本按美化 JSON 解析（与 `exportConfigJson()` 对应，便于直接编辑），否则按 base64 口令解析，共享同一校验与落盘通道。编辑器顶栏「导出/导入」按钮分别生成口令串小窗与粘贴导入小窗（导入结果显示成功/原因）。

### 13.2 持久化模式

炮塔/弹丸/模块定义采用**内存编辑 + bump 落盘**模式（`src/game/persist.ts`）：

- 注册表即真相：`TURRET_DEFS` / `PROJECTILE_ARTS` / `MODULE_DEFS` 是内存可变数组，编辑器直接改数组元素；任何编辑后调 `bump()`（界面重绘 + `saveAll()`）即时持久化。
- 存储：localStorage 三 key——`td-turret-defs` / `td-projectile-arts` / `td-module-defs`，值均为全量 JSON 信封 `{ version, data }`。素材库上传条目单独走 `td-asset-lib`（§11.5）；关卡走 `td-level-config`；堡垒类型库走独立 key（含自定义堡垒与出战选择，内置堡垒不持久化，覆盖内置 id 即视为自定义覆盖、删除覆盖即恢复出厂）。
- 加载：模块初始化时读取各 key，解析成功即**就地 splice 替换注册表内容**（保持 import 引用有效，引擎/渲染零改动）；无存储环境（sim/node）或解析失败均静默用出厂默认。
- 信封版本：当前 version = 2；读入 version 1 数据时按旧语义迁移（`fireRate` 取倒数，缺失/0 跳过）并回写新信封；其余版本号丢弃用默认。
- 重置：「重置」按钮调 `resetPersistedToDefaults()`——出厂快照（加载替换前留存）就地替换全部注册表并清除存储 key，刷新后不回魂。模块库另有单独回出厂入口。
- 跨设备搬运不经 localStorage，由口令通道（§13.1）完成：导出口令 = 当前内存注册表快照，导入 = 校验后就地替换 + 落盘，与本地持久化共用同一份数据。

### 13.3 模拟回归（scripts/sim.ts）

`scripts/sim.ts` 是无头模拟验证脚本：esbuild 打包后用 node 运行，覆盖各编辑器设计文档的关键验收口径（炮塔/弹丸/堡垒/关卡/素材/口令/粒子/特效点均有用例组）。

**运行方式**（项目根目录为 cwd，素材文件断言按 `public/res/` 相对路径读取）：

```bash
npx esbuild scripts/sim.ts --bundle --platform=node --format=esm --outfile=/tmp/sim.mjs
node /tmp/sim.mjs          # 输出逐条 PASS/FAIL，末尾 ALL CHECKS PASSED
```

末尾汇总打印 `ALL CHECKS PASSED` 或失败计数，有失败即非零退出（汇总在真正末尾，尾部用例失败同样被门禁捕获）。个别素材字节级一致性断言需经环境变量 `TD_TOKEN_FILE` 传入口令文本文件（base64 配置口令，用于比对库内 PNG 与口令内嵌 dataURL）。

**框架约定**：

- **确定性**：引擎逻辑不调用 `Math.random`；精度散布、导弹摆动相位和出怪位置均由 `eventRandom(eventId, stream)` 派生。需要隔离散布的测试应显式把临时武器定义的 `accuracy` 设为 0，并在用例结束后恢复；粒子/特效侧的角度与抖动同样保持可复现。
- **断言**：`check(name, cond, detail?)`——通过打印 `PASS`，失败打印 `FAIL` 并计入失败数；用例名标注所属功能点。
- **驱动**：`run(s, seconds, dt = 0.05, perTick?)` 以固定 dt 推进引擎 `tick()`；`arena()` 构造资源拉满、进入交战态、无炮塔的最小场景；`mkTurret(s, defId, x, y)` / `mkEnemy(s, kind, x, y, hp)` 放置测试实体（敌人钉住一个场外不可摧毁的假物体，不移动）。
- **隔离**：LEVEL 可变，用例间以出厂快照 `restoreLevel()` 无损恢复；临时炮塔/弹丸定义以 push + 用后 splice/pop 摘除（成对的 mk/drop、mkEntry/popEntry 助手）注入注册表，不污染后续用例；改动过出厂表字段的用例负责恢复。

**加用例约定**：按功能分组，以 `console.log('== 组名 ==')` 横幅分隔；在组内构造最小场景（优先复用 arena/mkTurret/mkEnemy 夹具），用 `run()` 推进到断言时点，一条 `check()` 一个口径（cond 只读终态，detail 带关键观测值）；涉及配置解析/口令的用例直接调 `parseConfig/applyConfig/serializeTurretDefs` 等纯函数做往返断言，素材/分层用例调 `validateArt/turretLayerSrcs/turretArtState/turretRenderKey/muzzlePos` 等纯函数，特效点用例调 `emitFortressEffects()` 传入双池并以返回的发射计数断言。新增用例不得破坏确定性（不得引入非种子随机/真实时钟依赖），且必须落在末尾汇总之前。
